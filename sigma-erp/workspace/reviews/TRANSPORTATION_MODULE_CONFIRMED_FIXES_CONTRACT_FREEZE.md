١. مسارات JSON وResult/Results ومرشحات/count/page والمخرجات تبقى متوافقة. `TripSheet.query` يمرر grid الحالي. لا sort UI جديد أو حالة فوترة مستنتجة.

٢. يضاف إلى TransportationAgreementItem حقل `DateTime? TripDate` مستقل عن التدقيق. AddExtraTripAsync يحفظ يوم ووقت tripDate المرسل كما هو wall-clock؛ إذا كان غير مرسل يحافظ على default اليوم الحالي القائم. وقت الرحلة المرسل TripTimes يظل صاحب الوقت عند وجوده. القارئ يستعمل TripDate قبل fallback التاريخي CreatedAt، مع نفس تركيب الوقت. لا تعديل لـHandleAudit ولا backfill للتاريخ الذي فُقد؛ التاريخ الجديد قابل للحفظ ولا تضيع دقة الوقت المرسلة. إعداد EF datetime2 متوافق؛ الخاصية لا تصبح مدخلًا عامًا لتعديل البنود بلا حاجة.

٣. مسار الإضافية يفحص اتفاقية tenant/live، وكل موقع غير null موجب وحي ومملوك، ووقت داخل اليوم إن أرسل، وتاريخ فعلي إن أرسل. لا يُفرض مبلغ موجب أو موقع إلزامي جديد، ولا تغيير معنى Notes/No في هذه الشريحة. تستعمل رسائل التحقق الحالية عند انطباقها. لا حظر جديد للإضافية بعد الإغلاق ولا حالة أعمال جديدة.

٤. كل قارئي Trips/scheduled وextra يرشحان الطفل الحي والمتوافق مع المستأجر، ويحافظان على scope الأب. يولد المجدول من max(بداية الطلب، StartDate.Date)؛ لا سياسة تاريخ نهاية مجهولة. استعلام الإضافية يملك ترتيبًا ثابتًا بالتاريخ ثم الهوية قبل paging؛ عمود grid يعمل قبل count/page. يجوز تحويل Includes إلى scalar projection محدود وتحريك الفلاتر قبل materialization ما دام عقد الحقول/الحساب/الترتيب والنتائج محفوظًا؛ لا استبدال بالذاكرة التشغيلية المخبأة. لا قياس سرعة مزعوم.

٥. تحديث بند مستقل مرتبط باتفاقية يستعمل حارس الأب tenant/live/not closed تحت قفل كتابة الاتفاقية الحالي نفسه `ExecuteUniqueWriteAsync<TransportationAgreement>`، ويحافظ على full snapshot/owning state عند تحديث الأصل. بنود غير مرتبطة تبقى على عقدها الحالي. لا تعميم منع حذف اتفاقية مغلقة خلاف العقد السابق، ولا اختراع صلاحيات.

٦. TransactionItem.Quantity فقط كمية18,6 وفق QuantityNumberPolicy؛ DTO/service يرفضان المقياس الزائد والمدى غير القابل للتخزين، ولا تقريب للمدخل. الواجهة quantityKind=quantity والحدود المشتركة/رسالة FieldError؛ السعر والضريبة والخصم والمبالغ ليست كميات. الحسابات المشتقة الحالية خلفية، ولا إعادة صياغة مالية.

٧. السبعة مستهلكون يراقبون data-free contextChanges؛ يلغون القراءات ويبطلون الصفوف/العدادات/التفاصيل/التأكيدات/المخرجات وتحضير الطباعة. triggers تبقى صالحة لاستعلام جديد؛ لا إعادة قراءة آلية بمعرف محفوظ من سياق سابق. المحرر يبطل حتى إعادة فتحه مع حفظ المسودة محليًا ومنع إرسالها في السياق الجديد. confirmation يلتقط revision. الكتابة المرسلة لا تُلغى أو تكرر تلقائيًا؛ callback قديم لا يغلق جلسة جديدة ولا يعيد ملء صفوفها أو يمسح خطأها. takeUntilDestroyed يبقى لعمر المكوّن.

٨. Customer/Branch/Vehicle المعتمدة تستخدم finite ناجح ثم ReferenceLookupBindings watch مرة واحدة؛ defaultIfEmpty يعيد الفشل لمسار Retry. حفظ labels/IDs/dirty، ومسح context دون إعادة دمج أسماء قديمة، وdisableRetainedOptions=true في المحرر مع optionDisabled عند انطباق المصدر. Driver وTransportationAgreement/GetSelect وAgreement/GetSelect مصادر مباشرة بلا opt-in؛ لا كاش جديد. Invoice يقرأ `Agreement/GetSelect` حاليًا عمدًا، ولا يتغير ربطه المالي.

٩. required initial/filter bootstrap عبر ReferenceLookupStatus يشارك مؤشر الصفحة، بلا مؤشر Select داخلي. حوار التفاصيل والخيارات يستخدم مالك StateMessage/Status محليًا واحدًا؛ save/actions/export عالمي. UI flags/errors/Retry/aria-busy وحراسة الخروج تظل قائمة. خطأ أحد الأعضاء لا يخفي تقدم بقية batch، وRetry لا يبدأ أثناء pending. shared table/button يملكان suppression؛ لا palette/loader/timer جديد.

١٠. لا تعديل application guide من العاملين؛ الجذر يحدث `UserGuide/content/transportation-guide.ts` بعد الدمج. ملفات scalar الأمامية حصرية لعاملها، ملفات الخلفية حصرية لعامل الخلفية، والاتفاقية/Trips/TripSheet والوثائق/الدليل للجذر. لا generated packets أو migrations أو snapshots أو مراجع معتمدة تُعدل. عند تعارض العقد يوقف العامل الجزء ويبلغ الجذر. يبقى نشر المخطط والبناء/الاختبارات/التشغيل عند المالك.

العقود الجديدة غير المجمدة: endDate للإغلاق وأثره، هوية حدوث الرحلة وحالات التنفيذ/التراجع والتعديل والجماعي، أهلية المركبة، قوالب مخرجات جديدة، وربط الفواتير وقواعدها المالية. تفويض أقرب سيناريو لا يملأ حقول خادم أو آثار محاسبية مجهولة. لا تسأل المهمة الحالية عن هذه الأجزاء؛ تسجل بوضوح كفجوات متبقية.

## تعديل أ١ — عمر التأكيد المشترك

كشف الدمج أن unsubscribe لنتيجة ConfirmationDialogService يبقي overlay غير محسوم مفتوحًا. الجذر يصلح المالك نفسه: finalize يغلق فقط dialog الخاص بالاشتراك إذا لم يصدر قرار، ولا يغلق بديله أو يعيد تفسير قرار resolved. وثقت القاعدة في UI9/10 والمهارة، وأعيدت الحزم بالمولد. إلغاء guard يؤول إلى false بدل قبول تجاهل أو كتابة. لا تعديل صلاحيات أو مظهر جديد.

## تعديل أ٢ — مخرج الرحلات الكامل بطلب واحد

النتيجة الحالية للتقرير/التصدير هي كل المطابقين بالفعل؛ تغيير طريقة تجميعها لا يغير نطاق العمل. يضاف query اختياري `allRows=false` إلى GET الثلاثة `Trips` و`TripSheetScheduled` و`TripSheetExtra`. عند true، يستعمل القارئ نفسه بنفس القيود والإسقاط والفلاتر والترتيب، ويعيد جميع المطابقين مرة واحدة في Results نفسه مع pageNo=1 وtotalPages=1 لغير الفارغ و0 للفارغ، وpageSize=max(1,totalCount). الافتراضي يبقي clamp/paging القائمين.

مستهلكو getAllTrips في الواجهة يرسلون allRows=true بدل تكرار التوليد لكل صفحة. يرفضون الغلاف الفاشل أو طول entities المختلف عن totalCount؛ لا إنتاج ملف ناقص إذا كان خادم أقدم لا يدعم العلم. الإلغاء/التحميل/خطأ Retry يظلون عند المالكين الحاليين. لا كاش تشغيلي ولا endpoint أو DTO أعمال جديد ولا رفع حد paging العام. نشر الخادم المتوافق يسبق الواجهة؛ حجم المخرج الكامل وSQL/الذاكرة/التوقيت قبولها عند المالك. التوليد الافتراضي الافتراضي ما زال مطلوبًا لحساب الفلاتر والعدد، ولا نزعم استبداله بحدث محفوظ غير متعاقد.

## تعديل أ٣ — تبويبات محرر اتفاقية النقل والكاش

طلب المالك «Open Transportation Agreement خلى الشاشة تابات وظبط الكاش». نطاق M: المحرر الحالي في الإنشاء/العرض/التعديل، ضمن نفس EditorDialog والنوع01 ونمط الخلفية2؛ ثلاثة تبويبات بالمالك EditorTabs: البيانات والأسعار، جدول الرحلات وأيام العمل، الملاحظات. نموذج واحد، panels مركبة مع hidden، وتكشفها printing كلها دون تبديل التبويب؛ فشل الحفظ يختار تبويب أول حقل غير صالح قبل focusField. لا حقول أو API أو قواعد مالية جديدة.

يبقى Customer/Vehicle/Branch GetSelect في مصادر الكاش المعتمدة بقراءة finite ناجحة ثم watch منفصل؛ Driver/GetSelect مباشر لأنه بلا source opt-in. لا كاش محلي أو طلب عند تبديل تبويب. إعادة المحاولة وbootstrap لا يعيدان كل الخيارات القديمة: يُحتفظ فقط بالمعرفات المختارة والتسميات اللازمة، مع disabled للاختيار الغائب عن الرد الناجح؛ تحديث الكاش لا يغير قيم النموذج أو dirty. فشل الغلاف/HTTP/الاكتمال الفارغ وRetry وتدمير الاشتراكات وعزل السياق والتحميل المحلي تبقى قائمة. يفحص الحفظ أهلية الاختيارات الحالية قبل إرسالها، ويبقى الخادم صاحب التحقق النهائي.

الدليل المرجعي المقروء لهذه الشريحة: نقطة دخول speed-analysis وقسم النقل، ومتحكم C1141 بتاريخ٢٨ أكتوبر، الأصل application.js:299036–299252، خاصة مجموعات الأيام والمرجعيات والبحث. المقارنة السابقة في التقرير تثبت غياب فصل شرح نقل مطابق بتاريخ٢٧؛ تبويبات العرض قرار المالك وUI13، وليست تصميمًا مستوردًا من سبيد. لم تعتمد أهلية المركبة التشغيلية من Vehicle/GetSelect. الحزم الثماني -Check ناجح قبل PHASE03/05/06. لا تعديل خادم/EF/فهارس؛ قياس تحميل cold/warm وقبول RTL/الثيمين/المقاسات والطباعة عند المالك.
