# عقد إصلاح ملاحظات مراجعة العملات

يستهلك هذا الإصلاح العقود المالية القائمة والخطة المعتمدة، ويعالج النتائج الثماني في CURRENCY_FULL_STACK_REVIEW دون فتح الشرائح المحاسبية التي سجلها التقرير بوصفها غير منفذة.

| النتيجة | العقد المستهلك للإصلاح |
|---|---|
| الإيداع والبطاقات | المحول الحالي أساسي فقط. مصدر مؤهل حي ذو عملة أساسية وقيد مصدر مرحل حي ومتوافق مع العملة؛ لا استهلاك لمسودة أجنبية أو إعادة تفسير مبلغها. نفس الأهلية في الاختيار والحفظ والاعتماد، مع فحص البنك الهدف الأساسي. رفض خادمي قبل الأثر، ورسالة مفهومة؛ لا تحويل بسعر ثابت. |
| الاستلام | قبول معاينة صريحة يدخل جذر المستند المتتبع في مسار حفظ اللقطة ولو كانت وحدها التغيير؛ لا إسناد استخدام مفترض أو التفاف على حارس الحفظ. |
| السعر الرجعي | كتابات السعر المؤرخ إضافة/تعديل/حذف تستهلك مالك الفترة المفتوحة الموجود، تحت قفل كتابة العملة. السعر المستخدم يبقى مقفلًا؛ لا تصحيح تاريخ تلقائي. قطع التقييم مرتبط بمالك لم ينفذ بعد ولا تُخترع له بيانات. |
| سياق تعريف العملة | تصفير القراءات/البيانات القديمة وإبطال المحرر والتأكيدات عند تغير السياق، مع رقم مراجعة وفحص الهوية. الكتابة التي أرسلت بالفعل تستمر دون تكرار، ولا تُطبق استجابتها على جلسة جديدة. |
| تأكيد مصادر الشراء والاستلام | callback مربوط بسياق وهوية مصدر ومحرر صالحة؛ يلغى عند تغير السياق ولا يعيد بياناته. |
| سعر الأساسية | تعريف الأساسية إلى نفسها1 دائمًا؛ الخادم يمنع قيمة مختلفة والمحرر يعرض1 ويعطل الحقل. لا معالجة خاصة للبيانات التجريبية. |
| الدليل | تصحيح وصف المسودات المنفذة، وتوثيق حظر المحولات غير المتبنية وحراس الفترة والسياق؛ تبقى حدود الترحيل والتسوية والتقييم واضحة. |

الأشكال القائمة محفوظة: قائمة تعريف مع محرر حواري، محررا مستندات ماليان، ومحولات بنكية ذات اعتماد. لا تغيير DTO أو حقول Grid أو أسعار/مجاميع حسابية أو صلاحيات. المال يتبع سياسته الحالية. مرجعية Speed/Odoo والعقود والتحميل والكاش والفهارس موثقة في المراجعة الشاملة؛ لا حاجة لقرار مالي جديد لإغلاق ثغرات التبني.

التنفيذ مصدر فقط؛ لا بناء أو اختبارات أو متصفح أو قاعدة بيانات أو هجرات أو commits. تُراجع الفروق على مستوى كل مستودع وتُحدّث سيناريوهات القبول والدليل عند المصالحة.

الملكية: وكيل البنوك يملك خدمتي CashDepositService وCardTransactionBankTransferService فقط؛ وكيل الواجهة يملك محرر/قائمة العملات وتأكيد مصدري أمر الشراء والاستلام فقط؛ الجذر يملك CurrencyService وملف أسعارها وحارس البيانات وخدمة الاستلام الخلفية والرسائل والدليل والوثائق والمصالحة. لا تعديل ملف مورد مشترك من وكيل؛ يرسل مفاتيحه المطلوبة للجذر.
