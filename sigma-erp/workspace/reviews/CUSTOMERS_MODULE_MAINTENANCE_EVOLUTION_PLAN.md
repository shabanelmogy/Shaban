## الهدف والجرد

تصحيح الانحرافات المؤكدة عن الكتب الحالية في الشاشات الفعلية، مع مراجعة عقود الحقول والصفحات والتحميل والكاش والإلغاء والمظهر والترجمة والإتاحة والأداء. لا إعادة تصميم للسياسات المالية ولا حذف بيانات أو فرض صلاحيات جديدة.

| الشاشة | المسار الفعلي | الشكل والمالك |
|---|---|---|
| الأفراد | `/IndividualPartner` وأبناء الإنشاء والعرض والتعديل | النوع ٣، نموذج متدرج، خلفية نمط ٢ |
| الشركات | `/CompanyPartner` وأبناء الإنشاء والعرض والتعديل | النوع ٣ وحوار مسودة سائق تابع، خلفية نمط ٢ |
| التنبيهات | `/Alerts` | قائمة قراءات تشغيلية مكتملة من مصدر تنبيهات العملاء، وليست سجل تحرير عام |
| تحصيل الديون | `/DebtCollection` | تقرير تشغيلي بإجراءات متابعة وحظر وحوار تاريخ؛ حد البيانات الحالي مجمد ولا يتحول إلى تقرير مكتمل افتراضيًا |
| تقرير المتابعة | `/followUpReport` | النوع ٧، تقرير بإجماليات خادم |
| ملخص الأرصدة | مسار ملف `BalancesSummary/balances-summary.routes.ts` كما يستورده ملف مسارات الصفحات | النوع ٧ مع عقد صفحات وتصدير كامل عبر المالك الحالي |
| أعمار الذمم | مسار ملف `ReceivableAgeAnalysis/receivable-age-analysis.routes.ts` كما يستورده ملف مسارات الصفحات | النوع ٧ مع صفحات وخيار صفوف كاملة موجود |
| كشف الحساب | مسار ملف `StatementOfAccount/statementofaccount.routes.ts` كما يستورده ملف مسارات الصفحات | النوع ٧، استجابة مقطعية وحسابات خادم |

المرجع: كتالوج الشاشات الحالي؛ مكونات الخطوات والأقسام والتحقق المشتركة، قائمة العمل المعتمدة، ومكونات صفحة التقرير وأفعاله والطباعة والجدول. يحكم المصدر الحالي السلوك الفعلي، والعقود الحالية تحكم القرارات التجارية.

## أثر التغيير وتصنيف الفجوات

| المجال | التصنيف | الأثر والحدود |
|---|---|---|
| عقود بيانات الأفراد والشركات والكتابة | إبقاء ومراجعة | لا تغيير حقول أو معرفات أو حسابات أو حذف أو انتقالات غير مدعومة |
| متابعة المراجع المرجعية | توسعة داخل المالك الموجود | تبني المصدر المشترك للقراءة الأولى والمتابعة وإعادة المحاولة؛ لا تخزين جديد ولا تحويل كل قراءة إلى كاش |
| التحميل والإلغاء | إصلاح | مالك مرئي واحد لكل عملية مع بقاء الانشغال والأخطاء وإعادة المحاولة؛ التقرير والصفحة عام، المساعد والحوار محلي |
| الجداول والتصفية والتصدير | إبقاء أو إصلاح مؤكد | تطابق الحقول ومفاتيح التصفية والعدد والصفحة والمخرجات، دون اختراع عقد بيانات كامل |
| العرض الحديث والإتاحة | إصلاح | تحقق مستقل فعليًا، قوالب وإشارات وحقن وأعمار اشتراكات؛ لا ترحيل قسري لزون أو النماذج التفاعلية |
| الخلفية والاستعلامات | مراجعة وإصلاح مؤكد محدود | إسقاط وحدود وقراءات مكررة ومرجعيات وتحقق وحفظ؛ لا توازٍ على سياق بيانات واحد ولا تعديل صيغة مالية |
| الفهارس | تقييم فقط | مقترحات مدعومة أو سبب عدم الاقتراح؛ لا مهاجرات أو تعديل لقطات |
| أدلة المستخدم | تحديث | شرح من المصدر النهائي للثماني شاشات والحوارات، بنفس القارئ ودليل العملاء |

## بدائل القرار

اعتُمد إصلاح المالك القائم والمستهلك الحالي. رُفض إنشاء طبقة كاش أو قوالب عرض أو خدمات مالية موازية لأنها تكرر المالك وتزيد خطر تغير العقود. رُفض الترحيل الشامل إلى دون زون أو نماذج الإشارات لأنه ليس شرط امتثال للإصدار ٢١ ويحتاج عقدًا منفصلًا. لا تغيير مخطط أو سياسة مالية في الشريحة المجمدة.

## القرارات المفتوحة وحدودها

- بيانات البطاقات الكاملة ورمز الأمان: قرار سابق معلق يتضمن بيانات ومهاجرات؛ يظل خارج التنفيذ التدميري إلى أن يحدد المالك القرار الدقيق. لا يعاد تصنيفه كقرار منخفض المخاطر.
- تحصيل الديون: الاستجابة الحالية قائمة بحد ١٠٠ بلا عدد كامل. يبقى عقد التصحيح السابق محفوظًا، ولا اختراع لحلقة صفحات أو صيغة استجابة جديدة. أي توصية بتغيير اكتمال التقرير تبقى قرارًا معلنًا.
- اختلافات الحسابات والتقادم والأرصدة والحظر عند ظهورها تُعرض بدليل؛ لا تغيير مالي أو تقييد وصول باجتهاد العامل.
- أعمال سندات القبض والودائع الحالية والمهاجرات التي نفذها المالك موجودة مسبقًا خارج هذا النطاق؛ تحفظ ولا تعدل من هذا المسار.

## التنفيذ والتحقق

الجذر يجمد عقود الاستهلاك قبل التفويض ويتولى الأفراد والتنبيهات وتحصيل الديون والحوارات، ثم دليل المستخدم والترجمات المشتركة والتكامل والمطابقة. عامل الشركات يملك ملفات الشركات فقط؛ عامل التقارير يملك التقارير الأربعة فقط؛ عامل الخلفية يملك ملفات الخلفية المباشرة للعملاء فقط. لا ملف مشترك يحرره عاملان. كل عامل يقدم دليل مصدر لكل شاشة ونتائج السرعة والكاش والتحميل والعقود ومخاطر قراراته. لا يعلن عامل اكتمال المهمة العامة.

تطبق مراحل الاكتشاف والعقود والقراءة والمحرر والإجراءات الموجودة والتكامل ثم المطابقة. فحص الحزم الثماني الأولي ناجح. تفحص الفروق حسب المستودع وتحفظ التعديلات المسبقة. لا بناء أو اختبارات أو تدقيق نمطي أو متصفح أو قاعدة بيانات أو مهاجرات أو إيداع أو رفع؛ نتائج الوقت والشبكة وخطط الاستعلام والقبول البصري تسجل صراحة كتحقق معلق عند المالك.
