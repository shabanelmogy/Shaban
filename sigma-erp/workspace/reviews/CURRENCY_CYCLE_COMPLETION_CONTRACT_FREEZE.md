# عقد استكمال دورة العملات — تسليم الإصلاحات الحالية

طلب المالك تنفيذ لا مراجعة فقط. سياسات D1–D6 بالخطة المعتمدة ثابتة ولا يعاد طلب اعتمادها. هذا العقد يثبت شريحة إصلاح نتائج القسم١١ من المراجعة؛ لا يعتبر إنهاءها اكتمالًا للترحيل والتخصيص والتقييم والبنوك الأجنبية. تبقى عقود الشرائح المالية اللاحقة مطلوبة على مستوى الكاتب والقارئ والتخزين.

| الملاحظة | قاعدة التنفيذ |
|---|---|
| ر١ | تفاصيل الإيداع الحية ذات أصل حي غير مبطل تحجز مصدر القبض/الصرف، بما فيها المسودة وفق مالك السعة الموجود. تمنع تعديل/إلغاء اعتماد/إبطال المصدر؛ الحذف أو الإبطال يحرر الحجز، والاستعادة تعيد التحقق. نفس القاعدة بأعلام الإجراءات والكاتب تحت قفل التخصيص. |
| ر٢ | سطر المطابقة المحجوز بجلسة مكتملة حية غير مبطلة يمنع تغيير المستند البنكي المصدر. لا فك تلقائي للمطابقة؛ تصحيحها بإبطال الجلسة من مالكها الموجود. القفل بالترتيب: التخصيص ثم المطابقة ثم نوع المحول، داخل نفس المعاملة. |
| ر٣ | الاتفاقية والحجز غير المتبنيين للعملة الأجنبية يسعران التأمين بالأساسية. تثبت عملة المصدر في المنشئ والعرض، ولا يعاد تسمية المبلغ بافتراضي الطرف. لا تغيير مبلغ أو حساب تأمين أو حارس ترحيل. |
| ر٤ | رسوم الإيجار الأساسية تتحقق من الطرف وبيانات الفوترة والأساسية؛ تفضيل عملة الطرف ليس شرط أهلية لمصدر أساسي. |
| ر٥ | تعديل اتفاقية بيع محفوظة يستهلك عملتها المحفوظة. الإنشاء يحتفظ بقاعدة التهيئة الحالية، والمصدر المرتبط يحتفظ بعقده. |
| ر٦ | ينتهي سياق المحرر عند تغير سياق الجلسة. تلغى القراءات والتأكيدات ويمنع callback القديم؛ الكتابة المرسلة لا تلغى ولا تكرر ولا تطبق استجابتها على سياق جديد. لا ادعاء إصلاح الأبناء قبل تتبع عمرهم. |
| ر٧ | لا تعطيل للأساسية. يتحقق endpoint التفعيل قبل التغيير، ويحمي DbContext شرط وجود أساسية فعالة في الحالة الناتجة؛ يستخدم قفل Currency نفسه. |

## حدود العقود والمصالحة

الأشكال الحالية: محررات مالية ومولدات مستندات ومحولات بنكية ذات اعتماد، بلا قائمة أو API جديدة لهذه الإصلاحات. قواعد الحساب والتقريب والمخطط ثابتة. لا AutoMapper جديد. الرسائل الجديدة عربي/إنجليزي، والدليل داخل التطبيق يطابق قيود المصدر.

المراجع المستهلكة: نتائج المراجعة الشاملة القسم١١ وSpeed/Odoo المسجلان بها، وعقود اختيار المستند والقبض، وBE8/12/15 وUI28، وحزمتا الإجراءات والمصالحة بعد فحص الانحراف. لا تتخذ أسماء إجراءات Speed دليلًا على قواعده الخادمية أو المالية. لا بناء/اختبارات/متصفح/DB/هجرات/snapshots/commit.

الملكية المنفصلة: وكيل المحاسبة لحراس القبض/الصرف ومحولي البنك ومساعد استعلامهما؛ وكيل المستندات لمولدات التأمين والحجز ورسوم الإيجار واتفاقية البيع وعرض نوافذ التأمين؛ وكيل الواجهة لسياق محرري الصرف وفاتورة المورد؛ الجذر لتعريف العملة وحارس الحفظ والرسائل والدليل والعقود والمصالحة. تحفظ تغييرات المستخدم والأقران.

## ما لا تغلقه هذه الشريحة

الدفتر الأجنبي والتخصيص ذو مبلغي الطرفين وقيد الفرق وإلغاء آثاره، وجلسة التقييم التراكمي ومساهماته وقطع التاريخ ومنع التكرار، والقيمة الدفترية المرجحة للبنك، والتقارير متعددة العملات، والتسجيلات الضريبية المؤرخة. لا إزالة لحواجزها أو حقول شكلية تدعي اكتمالها. لا قرار مالي عام مفقود يعيد فتح D1–D6؛ قواعد الدول وتكاملها لا تقبل دون مصادرها الرسمية.
