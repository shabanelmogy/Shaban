# خطة تطوير الموارد البشرية والرواتب

هذه خطة للمراحل التالية، منفصلة عن إصلاحات المصدر الحالية. لا تعني اعتماد سياسات مالية جديدة أو السماح بتغيير بيانات فعلية. التنفيذ الحالي موثق في عقود الإصلاح والحساب والصرف داخل مجلد reviews. مصدر الحقيقة هو الخادم والنسخ المحفوظة، وليس إجماليات شاشة الموظف.

## الوضع المستهدف في الشريحة الحالية

إصلاح أخطاء الدقة والفلاتر والتنقل وعرض التسوية؛ استخدام إعداد أيام الشهر والحضور في الحساب؛ حفظ راتب مؤرخ مع أثر المدخلات؛ صرف جزئي أو كامل لموظفي النسخة المعتمدة بسند دفع وقيد، مع رصيد متبقٍ وعكس دفعة موثق. يلزم استكمال تحقق المالك وبناء المشروع وترحيل قاعدة البيانات قبل التشغيل. لا تمس هذه الشريحة القيود والرواتب التاريخية ولا تعيد كتابتها.

## القرارات المطلوبة قبل كل مرحلة

1. تحديد البلد والسياسات النظامية ذات الصلة دون تثبيتها داخل معادلات عامة.
2. تحديد وقت تثبيت استقطاع السلفة/القرض، ومعالجة الموظف المغادر والفترات السابقة.
3. تحديد توزيع الأيام نصف المدفوعة، أيام العمل مقابل أيام التقويم، وآثار الإلغاء والعودة.
4. اعتماد الحسابات لكل مكوّن؛ المخصص لا يتحرر دون حركة استحقاق أصلية مطابقة.
5. تحديد إقفال الرواتب، تواريخ القطع، مسار تصحيح الفترة المقفلة، وفصل المسؤوليات.

## التنفيذ والتسليم

كل مرحلة تبدأ بتحليل أثر على المنتجين والمستهلكين والبيانات الحالية، ثم عقد Frozen قبل تعديل المصدر. تستخدم نفس خدمات الرواتب والإجازات والقيود والمكونات المشتركة. لا ينشأ مسير موازٍ أو شاشة دفع بإجماليات يكتبها العميل. توثق أي migration وخطة توافق البيانات القديمة والتراجع، ويحدث دليل المستخدم العربي والإنجليزي مع التسليم.

التحقق المستهدف: تغيير راتب وسط فبراير والشهور ذات 31 يومًا؛ الالتحاق وسط الشهر؛ غياب وإجازة على التاريخ نفسه؛ خصم مجدول وآخر قسط؛ عدم كفاية حساب/فترة/طريقة دفع؛ صرف جزئي ومتزامن؛ إعادة إرسال بعد انقطاع الاتصال؛ عكس دفعة في فترة مفتوحة مع بقاء الأصل؛ إجماليات قيد الاستحقاق والسداد ومطابقتها. لا تعد المرحلة مقبولة بمجرد مرور تحليل المصدر.
