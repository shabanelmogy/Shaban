Existing approve-only Bill endpoint may remain; old reasonless unapprove must fail rather than bypass required reason. Repeated/stale/void/unknown decisions fail409; rejection never reopens through any endpoint. Read eligibility is advisory, writers recheck. Existing null legacy provenance unchanged/read-only except existing explicit legacy Bill approval compatibility, never assume null means rejected/pending history.
