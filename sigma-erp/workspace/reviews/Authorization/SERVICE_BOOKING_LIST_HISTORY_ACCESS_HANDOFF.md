## الحدود المستهلكة

- تظل القائمة مرتبطة بمنحة `VehicleServiceBooking.View`، والتصدير والاعتماد
  والإغلاق والسجل بمنحها المستقلة المقترنة بالعرض.
- يبقى `Customer.Lookup` اختياريًا: تسحب القائمة مع العرض وحده. عند فقده
  تزال قيمة العميل الخام والمطبقة ويوقف bootstrap والمراقبة، فلا يخرج
  تصدير أو طلب بقيمة قديمة.
- يتبنى `Customer/GetSelect` bootstrap محدودًا ثم مراقبة
  `ReferenceLookupBindings` من الخدمة. يبقى خطأ المصدر قابلاً لإعادة المحاولة.
- يلغى طلب القائمة والتصدير وقرار الاعتماد/الإغلاق وقراءة السجل عند فقد
  المنحة أو تغيير السياق. تستعاد القراءة التي انقطعت عند إعادة المنحة فقط؛
  لا تعاد محاولة فشل النقل أو نتيجة الأعمال تلقائيًا.
- حوار السجل محلي: رسالة حالة وRetry و`aria-busy`، بلا محمل الصفحة. يقرأ
  فقط مع `VehicleServiceBooking.History` ويخفي مخرجاته عند انتهاء الوصول.
- عمليات الاعتماد والإغلاق المرسلة تملك `trackWrite` وسياج HttpContext؛
  تثبت النتيجة الناجحة قبل النشر ولا تعاد العملية تلقائيًا بعد إعادة المنحة.
- يثبت تنفيذ الإجراء أن الصف نفسه عضو في البيانات الحالية ومعرّفه موجب
  وعلم صفه الحالي مناسب (`canConfirm` أو `canClose`) قبل القرار وبعده.
- يبقى المحرر والسجل خارج مضيف القائمة المحجوب كي لا تهدم مسودة المحرر؛
  يستدعي حارس المسار `canDeactivate` للمالك. يلتقط إغلاق المحرر صاحب
  سياق القائمة ولا يعيد تحميل سياق تغيّر أثناء الحوار.
- تغلق القائمة نوافذ `Select` و`DatePicker` و`MultiSelect` الملحقة بـ`body`
  عند خسارة النطاق أو منحة العميل أو التدمير، دون نقل التركيز لسياق منتهٍ.

## أدلة المرجع والمطابقة

- قُرئ `16-service-bookings.md` وC1206 بتاريخ ٢٨ أكتوبر: المرشحات،
  التصدير، الاعتماد، الإغلاق والسجل مثبتة كإجراءات واجهة؛ حذف/إلغاء المرجع
  ليسا ضمن واجهة Sigma الحالية ولا أضيفا.
- قُرئ C1207: السجل حوار قراءة مستقل مرتبط بالحجز؛ نفذ كحوار محلي مستقل.
- لا يثبت المرجع صلاحيات Sigma أو نطاق الفرع أو قواعد الخادم؛ يحكم العقد
  المجمّد تلك الحدود.

## مواصفات المصدر

- `list-access.spec.ts`: سقوط `Customer.Lookup` لا يحجب القائمة ويمسح
  المرشح؛ إلغاء قرار الاعتماد؛ نجاح عملية مرسلة بعد السحب لا ينشر أو يعيدها.
- `history-access.spec.ts`: إلغاء قراءة السجل وطمس المخرجات ثم الاستعادة
  بعد إعادة المنحة.

## المتبقي عند المالك

يبقى قبول البناء والاختبارات والتشغيل وقياس السرعة/SQL للمالك ضمن الحدود
المعلنة. على الجذر دمج الشريحة مع تغييرات الخدمة والمسار والدليل والجرد ثم
إعادة مراجعة الفرق المشترك.

## تكامل الجذر النهائي

أصلح الجذر فك انتظار القرار قبل إعادة فحص Confirm/Close، وأضاف حالات
نجاحهما. حصر فتح الحوارات والإجراءات في سطح غير مشغول ومنع تعديل مدخلات
محرر مركب؛ وغيّر نوع canDeactivate ليتوافق مع boolean أو Observable.
أصبح التصدير يملك محمل الصفحة ويلغي مرشح عميل فقد منحة اختياره، مع
تنقيح متزامن قبل الالتقاط. أصبحت تهيئة العميل بمالك ReferenceLookupStatus
مع خطأ watch وRetry، ويعيد revoke/regrant السريع ربط المراقبة المنتهية.
أزيل منع الإغلاق المحلي للسجل بعد الرفض. مواصفات المصدر ١١ للقائمة
وحالة للسجل، غير منفذة. التفاصيل النهائية في المطابقة المرتبطة بالجرد.
