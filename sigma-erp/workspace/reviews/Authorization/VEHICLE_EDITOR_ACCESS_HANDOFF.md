## المطابقة المصدرية

| الجانب | النتيجة في المصدر |
|---|---|
| العرض | يتطلب Vehicle.View؛ لا يطلب اختيارات التحرير |
| الإنشاء والتعديل | يستهلك vehicleAccess المشترك، مع المصادر المطلوبة Branch.Lookup وCarMake.Lookup وCarModel.View؛ الحفظ ينتظر نجاح المصادر المطلوبة |
| النشاط | يتطلب Vehicle.Activate عند تعديل محفوظ؛ يبقى IsActive الأصلي في payload دون المنحة |
| الفروع | التسجيل على فرع الأصل والوجهة، والتحويل على المصدر عند نقله؛ يتبع تجاوز المدير العقد المشترك |
| المصادر الاختيارية | لا طلب عند رفض VehicleType.Lookup أو CostCenterGroup.Lookup؛ يبقى FK المسودة/المحفوظ ولا يُمسح، ويُعطل البديل. عند السحب تبقى تسمية الاختيار المحدد فقط |
| عمر المسودة | يحتفظ المحرر ببياناته محجوبة عند تغير الممثل/سياق الفروع، أو عند route reuse غير مقبول فوق مسودة أو حفظ/رفع مرسل؛ لا bootstrap يمحوها |
| استعادة الوصول | القراءات الملغاة قابلة لاستئناف صريح/استعادة المنحة؛ لا إعادة تحميل للتفاصيل المكتملة فوق المسودة ولا حلقة retry بعد الخطأ |
| الإنهاء المؤجل | تُلغى القراءات والقرارات والتركيز والطباعة المؤجلة عند سحب الوصول أو تبدل المسار. يتتبع focusField الممثل وهوية المحرر |
| الحفظ المرسل | مستقل عن denied$/teardown؛ يحتفظ بنتيجته ونجاحه قبل حجب النشر، ويضبط CAN_PRESENT_API_OUTCOME. نجاحه لا يعاد لفشل التنظيف |
| الخروج المحلي | القرار lazy ويعيد فحص busy عند الاشتراك؛ يُتاح discard جديد بعد الرفض. يتجاوز notifier الرفض الأول وحده عند بدء القرار مرفوضًا، ثم يلغي أي انتهاء وصول لاحق |
| الكتالوج | منحة المحرر وCreate/Lookup المناسبان؛ POST مستقل ونجاحه latch قبل GET التحديث؛ لا إعادة POST عند فشل التحديث. تفصل catalogRefreshing عن catalogSaving، وتُحرس النافذة بهويتها وظهورها وسياقها |
| مسار نظيف جديد | تُغلق نافذتا الكتالوج وتُصفّر حالتهما، ولا يستجيب handler حفظ لنافذة مغلقة |
| إزالة المستند | منحة التنظيف لازمة لإزالة مرفق محفوظ، مع فحص قبل القرار وبعده؛ markRemoved داخل onRemoving بعد قبول القرار فقط |
| استبدال المستند | مسار محفوظ بلا Media.DeleteMedia غير قابل للاستبدال. يبقى id الأصلي مع path الجديد ليملك الخادم استبدال الصف التاريخي وفق العقد |
| الرفع | FileField يستهلك uploadRequirement وpublicationAllowed وpublicationCancelled$؛ يفصل منع نشر path قديم عن تتبع الرفع والتنظيف |
| القراءة الخاصة | FileLink يستخدم protectedResource='vehicle-document' مع requirement المحرر؛ لا static fallback ولا رابط توكن. Media.ReadVehicleDocument شرط القراءة الخاصة وحدها |
| الضمانات | تستخدم EditableRows مع حراسة المحرر وإلغاء قرار الإزالة عند انتهاء الوصول |
| واجهات المداخل | المضيف mounted ومحجوب/خامل عند الرفض؛ نافذتا EditorDialog تستخدمان accessRequirement/accessBlocked، وأداة بيانات التجربة مقيدة بمنحة محررها |

## مصادر البيانات والكاش والتحميل

| المصدر الفعلي | التصنيف والعمر |
|---|---|
| Vehicle/GetByWithNavigationsId عبر getDetails | قراءة تشغيلية مباشرة، مرة لهوية المحرر؛ إلغاء بالمسار/الوصول/التدمير، وفشل مع Retry |
| Branch/GetSelect عبر BranchService | مصدر cacheSelect مثبت؛ bootstrap محدود ناجح ثم watch منفصل عبر ReferenceLookupBindings؛ اختيار محفوظ وRetry وclear عند انتهاء السياق. الإبطال يبقى عند كتّاب Branch/الكاش المشترك |
| CarMake/GetSelect | مباشر؛ لا cacheSelect مثبت على CarMakeService، وتحديث صريح بعد إنشاء ماركة |
| CarModel/GetAllWithNavigations | مباشر عبر getCarModels؛ يحفظ label المختار عند تصفية الموديلات، وتحديث بعد إنشاء موديل |
| VehicleType/GetSelect وCostCenterGroup/GetSelect | مباشران اختياريان؛ خطأ وRetry مستقل لكل مصدر، ولا يمنع فشلهما حفظ بقية البيانات |
| Vehicle POST/PUT وCarMake/CarModel POST | كتابات مستقلة مع HttpContext وعمر نتيجة محجوب عند انتهاء الوصول |
| Media عبر FileField/FileLink/DocumentUploadTracker | المالكون المشتركون يملكون القراءة الخاصة والرفع والتنظيف؛ لا ناقل ملفات محلي موازٍ |

تتبع قراءات التفاصيل وbootstrap الاختيارات والحفظ أزواج startLoading/finalize
الموجودة في مالك الصفحة. قراءات إعادة خيارات الكتالوج تستخدم EditorDialog.saving
بمالك التقدم المحلي دون زيادة عداد الصفحة، مع busy/finalize مستقلين عن POST.
يبقى POST بزوج تحميل الكتابة الحالي. تحديث Branch المحتفظ ببياناته صامت عبر ReferenceLookupBindings.
الظهور الفعلي وتداخل portal/loader قبول تشغيلي معلق، وليس نتيجة فحص المصدر.

استُبدل forkJoin الشامل بمصادر مستقلة حتى لا يفقد نجاح مصدر بسبب فشل آخر؛
لا cache جديد ولا طلب لكل صف. لم يُقَس زمن الشبكة أو SQL، ولا اقتراح فهرس
جديد من هذا المحرر وحده؛ تظل فحوص الخادم والفهارس عند مسار الجذر الخلفي.

## الأدلة والمراجع

استهلك العامل عقد الجذر المجمد ومصادره المرجعية المسجلة؛ لم يغيّر عقدًا تجاريًا
أو ماليًا من دليل سبيد أو Odoo. روجعت تعليمات المشروع ومهارتا Sigma وAngular،
وكتل UI22 وUI28 وUI18 والملاك الفعليون FileField وFileLink وEditableRows
وCurrentBranch وReferenceLookupBindings وخدمات الاختيارات. قراءات الاكتشاف
السابقة ومقارنة سبيد محفوظة في عقد الجذر؛ لا يدعى قراءة جميع نوافذ المرجع.

فُحص parsing للـTypeScript وAngular HTML ووجود imports المحلية لملفات المحرر
الأربعة؛ النتيجة بلا مشكلات تحليل. فُحص scoped diff كاملًا وgit diff --check
داخل مستودع الواجهة، وفُحص الملف الجديد مباشرة لأنه untracked.
أضيفت **٢٧ مواصفة مصدرية غير منفذة** تغطي المنح والمسودة والممثل والنشاط
والفروع والكتالوج والقرار المؤجل والمرفقات وroute reuse والحفظ/الرفع المرسل.
هذه ليست type checking أو build أو نتائج tests؛ لا RED/GREEN مدعى.

## المتبقي عند الجذر والمالك

يتولى الجذر دمج المفاتيح والمسارات والقائمة والخلفية والمخزن الخاص والمشتركات
ودليل fleet-guide ثم المطابقة النهائية. لا مخطط جديد أو AutoMapper أو حساب
مالي أو CSS في ملكية هذه الشريحة، ولا migration مطلوبة بسببها وحدها.

يلزم قبول التشغيل للمنح والحقول والمرفقات والقرارات السريعة وroute reuse
والفروع وRTL والثيمين والمقاسات، والتحقق من عدم تكرار POST بعد فشل refresh
أو cleanup. يلزم التحقق من أنواع المواصفات والمحرر بالبناء/الاختبارات عند
تفويض المالك؛ المصدر لا يثبت نجاحها. ملفات الرفع غير المنشورة بعد تبدل
الممثل لا تُنظف باسم الممثل الجديد؛ لا يدعى orphan sweeper أو تعافٍ من تعطل
العملية، ويظل التخزين والتنظيف النهائي ضمن مسار الجذر/المالك.

لم تُنفذ builds/tests/lint/browser/DB/migrations/snapshots/commit/push أو نشر،
ولم يُستخدم وكلاء جدد. رسالة commit مقترحة عند دمج الواجهة بواسطة المالك:

`fix(fleet): enforce vehicle editor access and attachment lifetimes`
