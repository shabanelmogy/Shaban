# مطابقة وصول أداة تعبئة بيانات التجربة المشتركة

| التاريخ | ٩ نوفمبر ٢٠٢٦ |
| النطاق | مالك النموذج والمعاينة المشتركان، دون تغيير توليد البيانات أو بيانات الأعمال |

أظهر تتبع المصدر أن المعاينة تعيد فحص صلاحيات الحساب الحالي ومساره،
لكنها لا تربط نفسها بسياق المستخدم الذي فتح النموذج. كذلك كان تأكيد
استبدال القيم يسبق طلب التوليد دون إعادة فحص متطلب النموذج بعد قبوله.

يربط المالك الآن توافر الأداة والمعاينة والتطبيق بسياق المستخدم عند
تركيبه. لا يتيح تغيير المستخدم إلى حساب يملك المنح نفسها تطبيق اقتراحات
النموذج السابق. يعيد فحص المنحة والمسار والنموذج قبل إرسال طلب التوليد،
وتلغي قناة المنع التأكيد والقراءة عند انتهاء منحها أو سياقها، مع التخلص
من الاقتراحات وفك التجميد والاحتفاظ بمسودة محرر الأعمال الأصلية.

نجح تحليل المصدر والقالب ومواصفة الرجوع ضمن ٣٨ ملفًا في الدفعة، وفحص
الفروق. أعيد توليد الحزم الثماني من الكتلة الحالية وفُحصت مطابقة مراجعها.

أضيفت مواصفة رجوع للحساب الآخر مع بقاء المنح نفسها، وحُدّثت fixtures
المواصفات القائمة لتمثيل سياق المالك. لم تُشغّل المواصفات وفق حدود المصدر.
رُقي السلوك إلى كتلة الواجهة 26 ومهارة سيجما في الدفعة نفسها، وتُحدّث
الحزم بمولدها. تجربة المالك تشمل فتح المعاينة وتبديل الحساب أو سحب منحة
المحرر أثناء تأكيد الاستبدال أو التوليد، والتحقق من منع التطبيق وبقاء
المسودة. يظل التوليد نفسه وحفظ بيانات الأعمال تابعين لمنحهما ومالكيهما.
