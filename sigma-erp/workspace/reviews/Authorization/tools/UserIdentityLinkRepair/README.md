# أداة تهيئة بيانات الربط المعتمدة

هذه أداة محلية للعملية المعتمدة في15 نوفمبر2026 لشركة101007 فقط. تستعمل
نماذج ومالكي Identity الحاليين عبر ملفات source مرتبطة للقراءة، ولا تعدّل
مصدر التطبيق أو حراسات تهيئة الشركات. المستهدفون ثابتون، والخادمان وقاعدتا
البيانات وربط أدمن ERP24 والكود يخضعون لفحص صريح قبل الكتابة.

الأمر التالي فحص قراءة فقط:

```powershell
dotnet bin/Debug/net10.0/UserIdentityLinkRepair.dll --ids 5,9,14,15,16,17,18 --alias-14
```

إضافة `--apply` تنفذ العملية. استُعملت بالفعل بتفويض المالك، ونتيجتها
LinkedVerified موثقة في إيصال المراجعة. لا حاجة لإعادة تنفيذها.

يعني `--alias-14` قرار المالك الصريح بالبريد التجريبي المختلف للمستخدم14.
لا تُقرأ كلمة مرور صريحة ولا تُكتب بصمة إلى سجل أو ملف؛ تبقى البصمة في
ذاكرة العملية وتخزين Identity فقط. تضاف صلاحية View لفرع المستخدم الحالي
وتُحفظ صفات النشاط والافتراضي القائمة. لا تضاف صلاحية Transact أو Transfer.

راجع تقرير الفحص والتنفيذ في مجلد Authorization الأب لمعرفة التفويض
والمراحل ونتائج التحقق وحدود القبول داخل التطبيق.
