## العقد المستهلك والأدلة

يتبع هذا التبني عقد LEASE_CUSTOMER_SMS_CONTRACT_FREEZE السابق: لا إرسال
فعلي أو مزود أو رصيد أو سجل بيانات. SearchAsync وSimulateAsync قراءتان
محدودتان فوق العملاء واتفاقيات التأجير الحالية؛ لا SaveChanges أو شبكة
خارجية في المحاكاة. لا يُنشئ التبني دورة إرسال جديدة.

النوع قائمة تشغيلية مشتقة UI01 بقراءة BE17، دون محرر كيان. الأعمدة Code/
Name/MobileNo/Email/IsInactive مع Id للهوية، مطابقة DTO. الفرز والبحث
ومرشحات grid والCount/Skip/Take في الخادم؛ لا اختيارات مرجعية أو كاش جديد.
الاختيار للصفحة الحالية فقط ويتحقق من عضوية نفس كائنات الصفوف المحملة.

قُرئت نقطة دليل سبيد وفهرس الشروح؛ لا شرح SMS مستقل عُثر عليه في catalog.
قُرئت شاشة sidebar10-lease/09-sms-to-lease-customer وC0893 بتاريخ٢٨أكتوبر
بالمصدر raw/application.js:243007-243186. يثبتان البحث والاختيار والرسالة،
ومزودًا ورصيدًا وقالبًا وإرسال دفعات لدى المرجع؛ هذه الثلاثة الأخيرة
Blocked بالعقد السابق ولا تُخترع في عمل الصلاحيات. خيار الاتفاقية المفتوحة
موجود بالمرجع ولم يُعتمد في عقد Sigma السابق؛ يسجل فجوة وظيفية، ولا يحل
تبني الصلاحيات محل خطة تطويره. Odoo المحلي مكمل للتأجير ولا يوفر عقد مزود
Sigma أو مفاتيح منح هذه المحاكاة؛ ليس دليلًا لحسم إرسال فعلي.

الخدمة، ولا يمتد لأي Send/POST خارجي مستقبلي. تظل قاعدة المستخدم بلا فروع
مرفوضة بالفلتر العام، والمدير يمر بقواعد العملية والتحقق المعتادة.

## عمر الحالة والتحميل

واحد page loader للبحث والمحاكاة، start/finalize حتى عند الإلغاء مع
busy/errors/Retry. shell mounted hidden/inert عند فقد Search، وtable
disposable عند denial لغلق filter portals. request owner/sequence/context
تمنع النتائج القديمة، وwatch دائم بعد completion يلتقط rapid revoke/regrant؛
recoveryPending ينتظر busy دون إعادة فشل HTTP تلقائيًا.

مسودة الرسالة تبقى لنفس الممثل عند سحب Simulate؛ الاختيار والنتائج
المحمية تُمسح، والنموذج mounted hidden/inert بدل تدمير stateful form.
السياق الجديد يمسح قائمة/عدد/اختيار/رسالة/فلاتر ونتيجة الممثل السابق.
لا إحياء تلقائي لاختيار قديم أو replay للمحاكاة بعد regrant. طلبات القوائم
تستخدم applied search/grid مستقلين عن raw draft. ترك المسار أثناء قراءة
يسمح بالإلغاء؛ لا domain write أو تأكيد اختراعي. focus المؤجل يتبع المنحة
والسياق وDestroyRef بمالكه المشترك.

## الملكيات والتسليم

الجذر يملك هذا العقد وreviewed backend/rules/specs وregistry/route policy
والدليل والترجمات والجرد والتكامل. عامل bounded يملك مجلد LeaseCustomerSms
في الواجهة فقط، بما فيه الخدمة/routes/specs؛ لا تعديلات متداخلة أو shared.
بعد التنفيذ تدقيق مستقل scoped، parsing/import/XML/scoped diff ومطابقة
الدليل ضمن /UserGuide/lease. لا schema/AutoMapper/حساب مالي أو فهرس جديد.
الأداء/SQL وعدد الاستعلامات والظهور التشغيلي عند المالك؛ لا قياس مدعى.

يُقفل تبني صلاحيات الوظائف الحالية فقط بعد مطابقة كل السطوح. يظل الإرسال
الفعلي وتفاصيل مرجع المزود فجوات تجارية مسجلة بعقدها، ولا يسمى إرسالًا
منفذًا أو مؤمنًا. لا إعادة قرار مادي حُسم سابقًا.
