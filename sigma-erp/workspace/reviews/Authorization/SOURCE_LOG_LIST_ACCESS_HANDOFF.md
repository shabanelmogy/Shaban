# تسليم قائمة سجل الخدمة

| البند | القيمة |
|---|---|
| Status | Implemented — source-only |
| Owner verification pending | yes |
| التاريخ | ٩ نوفمبر ٢٠٢٦ |
| النطاق | `Fleet/ServiceLog/components/list/**` فقط |
| التحقق | مصدر وفرق ثابتان فقط؛ لا تشغيل |

- تقرأ القائمة تحت `ServiceLog.Search` فقط، وتفتح الإنشاء تحت Search + Add
  + Vehicle.Lookup. العرض يستعمل لقطة صف القائمة الحالية ذات المعرف الموجب
  ولا يطلب تفاصيل جديدة.
- مرشح الورشة اختياري تحت Workshop.Lookup: يلغي bootstrap عند السحب ويمسح
  القيمة الخام والمطبقة ثم يعيد القراءة بلا ID قديم. المصدر مباشر بلا cache
  أو watch؛ تفشل القراءة برسالة وإعادة محاولة عبر ReferenceLookupStatus.
- تلغى قراءة القائمة وخيارات الورشة عند رفض المنحة/تبدل السياق، وتستعاد
  القراءة المنقطعة عند إعادة المنحة فقط. القائمة وbootstrap الورشة يملكان
  تقدم الصفحة؛ المحرر يبقى خارج المضيف المحجوب.
- يلتقط callback إغلاق المحرر مالك سياق القائمة فلا يعيد تحميل سياق أحدث.
  `canDeactivate` للوالد يفوض للمحرر؛ تغلق نوافذ Select وDatePicker الملحقة
  عند فقد الوصول أو التدمير.
- قُرئت S253 وC1190/C1201 من لقطة Speed ٢٨ أكتوبر. إجراءات المرجع للتعديل
  والطباعة والتقرير وقراءة التفاصيل ليست ضمن الواجهة/العقد الحالي ولم تضف.

حُسم فرع التنفيذ كقيمة ثابتة وقت التسجيل. تعرض القائمة `branchName` من
لقطة DTO فقط بلا lookup؛ يبقى تنفيذ الحراسة الخلفية والجرد والقبول التشغيلي
عند الجذر ولا تدعي هذه الشريحة اكتمالها أو ترقية الجرد.

أضاف تكامل الجذر انتهاء منحة الورشة حتى بعد نجاح bootstrap المحدود،
وإلغاء قراءة قائمة محملة بمعرف الورشة القديم قبل نشرها. ضُبطت مرجعية
السياق لمنع إعادة تهيئة المصدر عند منحة غير مرتبطة، وأزيل مؤشر Select
المكرر. مواصفات القائمة خمس غير منفذة، وتشمل إلغاء القائمة المصفاة.
