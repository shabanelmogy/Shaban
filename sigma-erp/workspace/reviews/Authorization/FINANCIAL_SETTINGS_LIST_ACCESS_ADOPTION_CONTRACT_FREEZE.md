# عقد صلاحيات طرق الدفع ومراكز التكلفة

| البند | القيمة |
|---|---|
| Status | Frozen |
| Owner verification pending | yes |
| النطاق | PaymentMethod وCostCenter بقوائمهما ومحرراتهما وأفعال الصفوف |

| الحدث | طرق الدفع | مراكز التكلفة |
|---|---|---|
| فتح القائمة، البحث، الفرز، التصدير، التفاصيل | PaymentMethod.View | CostCenter.View |
| الإضافة | عرض + PaymentMethod.Create + Branch.Lookup + PaymentMethod.GetUserOptions | عرض + CostCenter.Create + CostCenterGroup.Lookup |
| التعديل | عرض + PaymentMethod.Update + القائمتين المساعدتين | عرض + CostCenter.Update + CostCenterGroup.Lookup |
| الحذف | عرض + PaymentMethod.Delete | عرض + CostCenter.Delete |
| تغيير حالة الصف | من خلال تعديل الحقل Active | عرض + CostCenter.Activate |

تحتاج تصفية مراكز التكلفة حسب مجموعة إلى `CostCenterGroup.Lookup` في
الواجهة. عند سحبها يُزال مرشح المجموعة وتظل القائمة متاحة لمنحة العرض.
يعرض وضع القراءة الاسم المحفوظ في التفاصيل دون تحميل قوائم المحرر.

تستخدم طرق الدفع نقطة `GET PaymentMethod/user-options` بدل مسار إدارة
المستخدمين المخصص لمدير الشركة. تعرض النقطة المعرّف واسم العرض من نفس
شركة المستأجر، وتستخدم منحة `PaymentMethod.GetUserOptions` المستقلة.
إسناد هذه المنحة لا يفتح إدارة المستخدمين. منحة الطرق العامة الأخرى
`PaymentMethod.GetSettingsOptions` تخص مستهلكًا مختلفًا.

تُحجب القوائم والمحررات عند سحب الوصول وتُلغى القراءات المعلقة. تبقى
مسودة المحرر في سياقها وتبقى نافذة الإغلاق متاحة. تظل الكتابات المرسلة
مستقلة ويُعاد فحص صلاحية التأكيد قبل إرسال أي كتابة. تحتفظ خيارات الفرع
بذاكرة المراجع الحالية. خيارات المجموعة ومستخدمي طرق الدفع قراءات مباشرة.
لا تغيير للمخطط أو لحقول الحفظ أو أثرها المالي.
