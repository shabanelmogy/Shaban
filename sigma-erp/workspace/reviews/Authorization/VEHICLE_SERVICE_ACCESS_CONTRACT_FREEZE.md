الشكل قائمة بمحرر مستند موجه UI02: رأس وثلاث مجموعات أطفال، دون ترحيل
مالي. التعريف مشترك داخل الشركة؛ تسجيل صيانة فعلية وحجز خدمة وسجلها
وحدات أخرى، ولا تمنح صلاحية التعريف إذنًا عليها.

القائمة والبحث والصفحات والفرز والتفاصيل والرابط المباشر للعرض تحتاج
`VehicleService.View`. الإنشاء يحتاج العرض و`VehicleService.Create`
واختياري المحرر اللازمين `ServiceItem.Lookup` و`Item.Lookup`.
التعديل يحتاج العرض و`VehicleService.Update` والاختيارات نفسها.
الحذف يحتاج العرض و`VehicleService.Delete` مع تحقق الاستخدام الخلفي.
تُعرض التفاصيل المحفوظة دون تحميل اختيارات التحرير. السعة الزمنية وأنواع
ملفات العمالة المحلية لا تُنشئ طلب اختيار خارجيًا جديدًا.

كل تغيير في الرأس والبنود والقطع والعمالة واختيار البنود وإزالتها يتبع
منحة حفظ المحرر. لا منح حذف مستقلة على مسودة أطفال داخل حفظ التجميع.
يتحقق الخادم من CRUD الموروث ومن ملكية الأطفال والمراجع في خدمة
VehicleServiceService. لا API أو منحة أو مخطط أو قاعدة مالية جديدة.
تظل مجالات الأرقام والحسابات الحالية عند مالكيها؛ تبني الوصول لا يغيّرها.

يُحفظ المحرر مركبًا عند سحب المنحة، مع حجب مضيفه وحوار اختيار البنود
ومنافذ Select المنفصلة. تُلغى القراءات والقرارات المنتهية بالسياق أو المنحة،
ويعاد فحص الوصول بعد الإقرار وقبل طلب جديد. يحفظ الإلغاء المحلي المسودة
عند الرفض، ويبقى قرار التخلص الصريح متاحًا بعد سحب الوصول. تُلغى
القرارات القديمة ولو أعيدت المنحة قبل الإقرار. تتبع كل إزالة عضوية الصف
الحالي. يمنع الحفظ دون تفاصيل محملة أو دون اختيارات مطلوبة ناجحة.

الحفظ والحذف المرسلان مستقلان عن عمر العرض، مع سياج النتيجة المحلي
والعالمي عبر HttpContext. يثبت نجاح الحفظ حتى لو حُجب نشره، ولا يعاد
إرساله. يُستعاد bootstrap الملغى عند إعادة المنح مع الاحتفاظ بالمسودة،
دون تكرار قراءة تشغيلية بعد فشل عادي أو انتهاء مؤشر تحميل.
الرجوع للمحرر والقائمة يحافظ على مرشحات المسار وفق مالكها الحالي.

مصادر القراءة: القائمة والتفاصيل تشغيلية مباشرة، وServiceItem/GetSelect
مصدر مرجعي مباشر بلا opt-in للمخبأ. Item/GetSelect يتبع مخبأ الاختيارات
الذي تبناه مصدر Item ومراقبته وإبطاله القائمين. لا توسعة لمخبأ التعريفات
التشغيلية. قراءة المحرر وتهيئة اختيارته المطلوبة مملوكتان لمحمل الصفحة،
وحوار اختيار البنود يستخدم بيانات bootstrap المحملة ولا يطلب شبكة أخرى.
