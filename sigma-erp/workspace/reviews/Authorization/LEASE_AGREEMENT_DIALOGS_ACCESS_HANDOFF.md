## المصادر المقروءة فعليًا

- تعليمات مساحة العمل وملف القواعد الحي كاملًا، ومهارة شاشات Sigma، وعقد الصلاحيات المجمد.
- كتاب الواجهة: الكتل 13 و18 و22 و26 و27 و28، وشكل الشاشة 09 للحوار الإجرائي.
- فهرس الوثائق والمراجعات الجاري، ومرجع Speed المذكور في العقد لشاشة الاتفاقيات؛ لم تُستخدم Odoo لحسم صلاحيات Sigma لأنها لا تثبت مفاتيح المنح أو العزل.
- المصدر الفعلي لكل الحوارات الأربعة عشر، ومالك `EditorDialog`، و`AccessViewPolicyService`، و`CAN_PRESENT_API_OUTCOME`، وخدمة اتفاقيات التأجير.

## النتيجة المصدرية

- أضيف مالك عمر محلي للميزة يثبت الممثل والمستند، وينهي الجلسة نهائيًا عند تبديل أيهما، بما يشمل `A→B→A` و`A→null→A`، مع استعادة منح الممثل نفسه دون مسح المسودة.
- فُصلت متطلبات القراءة والكتابة حسب `lease-agreement-access.ts`؛ يبقى الحوار المثبت في وضع منع عبر `EditorDialog.accessBlocked`، وتختفي الكتابة دون هدم الحوار.
- حُرست مداخل الكتابة المباشرة، وأُضيف سياق `CAN_PRESENT_API_OUTCOME` لكل mutation في النطاق، مع fence لسحب المنحة أو تغيير الممثل/المستند أو هدم المكوّن.
- أُلغيت قرارات التأكيد المفتوحة عند انتهاء الوصول/السياق، مع إبقاء التجاهل المحلي متاحًا إذا بدأ بعد المنع، وحُرست عمليات التركيز المؤجلة بعمر الجلسة.
- وثائق الاتفاقية بقيت `HasDocument` ورفعًا ذريًا فقط؛ لم يُخترع viewer API أو رابط ملف.
- بقيت قراءات الحوار تحت مالك التحميل المحلي القائم، وبقي تحرير نتيجة الكتابة المرسلة منفصلًا عن هدم العرض.

## المواصفات المصدرية غير المنفذة

أضيفت مواصفات محلية لعمر الجلسة تغطي الفصل بين القراءة والكتابة، سحب/إعادة منح الممثل نفسه، التبديل النهائي للممثل، تغيير المستند، وسياق النتيجة المرسلة. لم يُشغّل runner أو compiler وفق الحدود الصريحة.

## فحوص المصدر

- نُفذ `git diff --check` لنطاق الوحدة: لا أخطاء whitespace؛ ظهرت تحذيرات تحويل LF/CRLF الموجودة في مساحة العمل.
- فُحصت علامات الدمج في النطاق، ولم تظهر علامات تعارض.
- لم يُشغّل build أو test أو lint أو typecheck أو browser أو قاعدة بيانات أو migration أو commit.

## قبول المالك المعلّق

- تشغيل المواصفات والبناء وفحص القوالب والربط في Angular.
- تجربة السحب وإعادة المنح، وتبديل الممثل/المستند، وقراءة read-only لكل حوار، وتأكيد بقاء المسودات.
- تجربة mutation مرسلة أثناء السحب والهدم، وتحقق loader/feedback في التشغيل الفعلي.
- لا حاجة schema أو migration من هذا النطاق.

## نتيجة التدقيق المستقل

- أُغلقت في المجموعة الكبيرة المملوكة قراءات السياق واللوكات المركبة عبر cancellation/publication guards واستعادة واحدة بعد إعادة المنح دون patch لمسودة dirty.
- أُغلقت overlays المنقولة إلى `body` عبر APIs العامة لـSelect/DatePicker عند منع الكتابة أو انتهاء السياق.
- أُعيد تدقيق حواري التمديد والـhelper بعد إصلاح settings وEditableRows والمؤقت المؤجل، ولم يبق finding جديد في هذا النطاق.
- أظهر التدقيق اللاحق نقاطًا في تمديد فترة السعر وأغلقها مصدرّيًا: بقيت صفوف السياق المقروءة تُحمّل في وضع القراءة فقط مع حصر حراسة الإضافة في الصف الجديد، وانتقلت لوكات Staff/ClauseType إلى عمر القراءة ومتطلبها المجمد بدل ربطها بمنحة الكتابة. كما حُرست أخطاء الطلبات بهوية الطلب والمستند والوصول، ومنع restoreForm من إعادة تمكين نموذج بعد السحب، وحُرس استعلام DOM للتركيز المؤجل قبل تنفيذه.
- أُعيدت مراجعة Documents وDeposit بعد التدقيق: metadata refresh عند regrant، رفع متعدد غير terminal، وحراسة الخطأ/finalize؛ وأصبحت قرارات التجاهل/الحذف lazy وقابلة للإلغاء.
