## القرار والمصادر

دورة الاستحقاقات في Sigma تملك شاشة workspace واحدة بقراءة تحضير وقراءة
تشغيلات محفوظة، وتفصل تفاصيل التشغيل عن التبويب العام. مفاتيح الخادم
الموجودة في `ReviewedPermissionOperations` تغطي التحضير والتشغيل والتفاصيل
والحفظ والحذف والإلغاء والقيد والسجل، بينما يضيف كتالوج الاعتماد المشترك
مفاتيح `Accruals.View` و`Accruals.ManageApproval` لقراءة الاعتماد واتخاذ القرار.

قُرئ شرح Speed للشاشة:

`references/speed-analysis/2026-10-28/sidebar/18-vouchers/screens/18-accruals.md`

ثم قُرئ كود الدورة المؤرخ:

`references/speed-analysis/2026-10-28/readable/controllers/C0472--tenant.views.crs.accounting.accruals.index.js`

Speed يثبت اختيار الشهر والتحضير والحفظ والتفاصيل والتصدير؛ لا يثبت مفاتيح
Sigma أو إنفاذ الخادم. لا توجد فجوة تحتاج مرجع Odoo لهذه الدفعة.

## مفاتيح المسار والأحداث

| المسار/الحدث | المتطلب المصدرّي |
|---|---|
| دخول المسار | `Accruals.Prepare` أو `Accruals.Runs` |
| تحضير الشهر | `Accruals.Prepare` |
| التشغيلات المحفوظة | `Accruals.Runs` |
| تفاصيل تشغيل | `Accruals.Detail` |
| حفظ التحضير | `Accruals.Prepare` + `Accruals.Save` |
| حذف تشغيل | `Accruals.Runs` + `Accruals.Delete` |
| إلغاء تشغيل | `Accruals.Runs` + `Accruals.Void` |
| قراءة الاعتماد | `Accruals.Detail` + `Accruals.View` |
| قرار الاعتماد | `Accruals.Detail` + `Accruals.ManageApproval` |
| القيد | `Accruals.Detail` + `Accruals.Journal` |
| السجل | `Accruals.Detail` + `Accruals.Log` |

التصدير وظيفة عرض محلية، ولا ينشئ مفتاحًا خلفيًا جديدًا؛ يحافظ على متطلب
القراءة الفعلي للتبويب الحالي. لا تُفتح تفاصيل أو أفعال تشغيل بلا المنحة
المقابلة، حتى لو كانت أعلام `canDelete` أو `canVoid` في الصف مفعلة.

## العمر والحالات

تُلغى قراءات التحضير والتشغيل والتفاصيل عند سحب منحتها أو تغير سياق الحساب
أو الشركة أو الفرع العامل، ولا تُنشر نتيجة متأخرة. الكتابات التي بدأت بالفعل
تستمر حتى نتيجتها ولا يعاد إرسالها تلقائيًا. عند سحب الوصول يُحجب workspace
وتُغلق النوافذ التابعة؛ إعادة المنح تعيد القراءة الحالية فقط.

يظل الاعتماد مالكًا مشتركًا لحراسة القراءة والقرار والتأكيد، بينما يظل القيد
والسجل قراءتين منفصلتين لا يفتح أحدهما الآخر. الاحتفاظ بمسودة شهر أو سبب
الإلغاء يخضع لحارس المغادرة الحالي.

## الفجوات والاستبعاد

تحديث قرار المالك في ٨ نوفمبر ٢٠٢٦: يسمح للمستخدم الممنوح بتنفيذ دورة الشهر
إذا كان نطاقه يغطي كل مصادرها. التحضير يستخدم فروع العرض، ويستخدم الحفظ
والاعتماد فروع تسجيل الحركات. عند حجب مصدر مطلوب ترفض الخدمة العملية قبل
إرجاع كشف جزئي أو حجز الشهر. الكشف المحفوظ وثيقة واحدة بفروع سطوره المحفوظة.
يسري شرط اكتمال العرض كذلك على القيد والسجل والاعتماد.

لا يغيّر هذا العقد الحساب المالي أو توزيع الفروع أو API/DTO أو schema. الترحيل
والحسابات والقبول التشغيلي والقياس البصري/الزمني خارج حدود source-only.
