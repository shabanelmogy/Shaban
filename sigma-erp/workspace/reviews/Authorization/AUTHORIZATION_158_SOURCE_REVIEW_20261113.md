| ٩ — الفلاتر | تُطبّق المرشحات النصية المقصوصة مرة واحدة، ويستخدم عرض القائمة وتعريف السجل الحي وقراءة التفاصيل معيار الحذف نفسه. تُسقط القائمة الحقول الخمسة المعروضة قبل جلبها. |
| ١٠ — الاختبارات | صُححت حالات المنح وتوقيت فحص رسالة الحفظ، وأضيفت حالات للفرع المسموح باستعراضه وتغيّر الوحدة بعد فحص المرشح والحذف المرتبط، وللمسودة والطباعة. تستخدم مواصفات الخدمة EF InMemory مع بديل صريح لقفل SQL Server. تظل تجربة القفل والترجمة الفعلية للاستعلامات على SQL Server ضمن القبول التشغيلي. |
