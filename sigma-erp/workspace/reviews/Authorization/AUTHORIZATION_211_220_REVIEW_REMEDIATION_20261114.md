## مطابقة مسار HTTP والرفض

يرفض `PermissionAuthorizationFilter` العملية إن لم توجد المنحة الأساسية ويُرجع **403**؛ `PermissionPrerequisites.HasRequiredGrantsAsync` يعيد **403** مع `AuthorizationPermissionPrerequisiteRequired` للمنح المستقلة المطلوبة. `BranchOperationRules` يحدد read مقابل write، و`BranchScopeRegistry` و`SiGmaDbContext` يراجعان فروع التعديل المحفوظة والجديدة وتغيّر النشاط وحالة المدير. الخدمة نفسها تراجع حالة الموافقة والمستندات المصدر والكمية والرصيد تحت الأقفال، وترجع رفض حالة العمل المناسب. واجهات الطفل المتقاعدة 211 ترفض **405** حتى المدير. لم يُنشأ مفتاح مصطنع لـVoid مرتجع الشراء؛ `POST /PurchaseReturn/{id}/void` يستعمل `PurchaseReturn.Update` وشرط View وفق annotation الفعلي.

مداخل الطلبات والأوامر: `POST /PurchaseOrder/from-job/{jobId}` يلزم `PurchaseOrder.Create` و`Job.View`؛ `POST /PurchaseOrder/from-requests` يلزم `PurchaseOrder.Create` و`PurchaseRequests.View`؛ و`POST /PurchaseRequest/{id}/purchase-orders` و`GET /PurchaseRequest/{id}/purchase-order-draft` يلزمان `PurchaseRequests.CreatePurchaseOrder`, `PurchaseRequests.View`, `PurchaseOrder.Create`. `PurchaseOrder.AddAsync` مع `LeaseQuotationId` يستلزم `LeaseQuotation.View`. كل عمليات القراءة تعيد فلاترها/فرزها/صفحاتها تحت نطاق الفرع، وExcel/print في PO/PR يتبعان إصدار البحث المطبق؛ لا تُستنسخ تفاصيل مستند مصدر مخفي في استجابة الرصيد.

## التحقق والحدود

**ما ثبت بالمصدر:** ربط المسارات بالمنح وخدماتها؛ وجود locks لكل aggregate؛ شرط نوع المرتجع في تفاصيل المستند؛ استعلامات الجرد والقائمة؛ إلغاء القراءات بعد revoke؛ وتسوية الكتابة المرسلة. مصدر Speed يثبت دورة الوالد وأوامره، بينما القبول على التطبيق يحتاج حالة أصل وفرع مستخدمين حقيقيين.

**ما نفذ:** `Generate-SigmaRecipes.ps1 -Check` بلا drift. اختبار .NET الموضعّي النهائي لبنود 211/216/217/219، حراسة الفلاتر والمصادر وامتداد الشركة، ومنع child 211، ومراجعة دورة اعتماديات الكتالوج: **43/43 نجاحًا، صفر فشل/تخطي** بعد إضافة حالتي Job/LeaseQuotation وتوسيع نطاق مرتجع الشراء. منفذا Angular أكدا نجاح فحص `ngc` و`tsc` الموجه، مع بناء Angular development ناجح لدى منفذ المرتجعات. نجح فحص Angular compiler آخر patch بتكوين TypeScript مؤقت ينحصر في route-policy وشاشات 216/217/219 ودليل الاستخدام؛ أزيل التكوين المؤقت بعد الاستخدام. نجح `git diff --check` الموضعّي والجرد المحلل في القراءة الختامية `190+24+38+9+2=263`.

**تعذر فحصان شاملان خارج نطاق 211–220:** فحص `ngc -p tsconfig.app.json` الشامل فشل في `TrafficFine/components/list/list.component.ts:101,138,146` لغياب `takeUntil` وتبعات النوع غير المحدد، و`TrafficFine/components/details/details.component.ts:120` لحقل `fineImageUrl` غير موجود، و`trafficfine.routes.ts:5` لعدم وجود `canDeactivate`. تشغيل `ng test --include=route-access-policy-211-220.spec.ts` فشل في **بناء كل مواصفات Angular** قبل Jasmine بسبب mismatches سابقة في `BalanceSheet`, `Equipment Rental/TimeSheet`, `Fleet`, `Rental`, `PurchaseRequest` numeric specs و`TrafficFine`. لذلك بقيت **حالة Jasmine الخاصة بسياسة المسار مكتوبة ولكن غير منفذة**. هذه ملفات متزامنة خارج الملكية ولم تُعدل ضمن هذه المهمة؛ فحص production الموجّه نجح.

**المعلّق/المستبعد:** لا توجد تجربة دخول مستخدمين وسحب grant أثناء modal على متصفح حي، ولا fixture SQL Server لمسارات 403/405 وسباقات الحجز وتخصيصات قيود الفروع وSave/Print الكبيرة؛ يلزم التحقق على الطبقة الفعلية ببيانات تستوفي شروط الفرع والمستند والحالة. واجهة PurchaseReturn الحالية لا تملك مخرجًا مثبتًا لـExcel/Print/Report رغم وجوده في Speed؛ يلزم عقد مخرجات مستقل قبل إضافته. لفرع تعريف `Provision` القديم قرار مالك مستقل في `PROVISIONS_ACCESS_CONTRACT_FREEZE.md`، وصفا الجرد 214/215 تاريخيان. لا هجرات أو تغييرات بيانات أو نشر في هذه المهمة.

استُخدمت قواعد الحوكمة وعقد الوصول في الدليل الرئيسي، وقواعد صلاحيات المسارات في الواجهة (UI26)، وقواعد مدخلات القوائم المحمية في الخلفية (BE9). روجع دليل سبيد لدورة الورشة والمشتريات بتاريخ ٢٨ أكتوبر، ثم تحليل القائمة وكود مرتجع الشراء `C1693` الذي يثبت وجود الطباعة وExcel والتقرير في المرجع. عقد مخرجات المرتجع ما زال مستقلًا، وقواعد المنح والفروع في هذه الملاحظات تستند إلى مصدر Sigma وعقوده. فهرس أودو المحلي متاح، ولا يلزم لتحديد سلوك حراس Sigma. هذه الجولة راجعت المصدر وتغييرات النطاق في المستودعين وطابقت حالات الجرد. نتائج البناء والاختبارات أعلاه تخص الجولات المسجلة، وقبول HTTP والمتصفح وSQL Server باقٍ.
