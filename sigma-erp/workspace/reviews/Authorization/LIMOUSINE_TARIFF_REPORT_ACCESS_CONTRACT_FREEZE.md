# عقد صلاحيات تقرير تعرفة الليموزين

| البند | القيمة |
|---|---|
| Status | Frozen |
| Owner verification pending | yes |
| النطاق | `/LimousineTariffReport` ومرشح العميل والبحث والأقسام والطباعة والتصدير |
| التاريخ | ٩ نوفمبر ٢٠٢٦ |

الشكل تقرير كامل غير مرقم، وفق UI20، يعرض أقسام رد
`GET LimousineTariff/GenerateReport` ويطبع ويصدر الرد الكامل نفسه.
تتطلب القائمة والرابط والبحث وعرض الأقسام والطباعة والتصدير المنحة
`LimousineTariff.GenerateReport`. لا منحة تصدير أو طباعة مصطنعة؛ كلاهما
إخراج محلي لنفس البيانات المسموحة.

مرشح العميل اختياري، لكنه يتطلب `Customer.Lookup`. عند غيابه تُعرض
التعرفة الأساسية دون طلب مصدر العملاء، وتزال أي هوية عميل من الطلب
والنموذج والنتيجة السابقة. اختيار تقرير خاص بعميل في الواجهة يتطلب منحة
التقرير واختيار العملاء معًا. يبقى فشل مصدر مسموح قابلًا لإعادة المحاولة، ولا
يحوّل مصدرًا مرفوضًا إلى خطأ اختيار إلزامي.

يطبق المالك المشترك نطاق الشركة في الخلفية؛ التقرير يقرأ تعريفات الأسعار
المشتركة داخل الشركة، وليس حركات فرع. لا تغيير للرد أو الحسابات أو الفهارس
أو المخطط. الخادم يفرض `GenerateReport` وطلب العملاء يفرض `Lookup` من
خلال الفلتر والمحلل وعمليات الكتالوج المراجعة. منحة اختيار العميل تحكم
مصدر الاختيارات؛ لا تُنشئ سرية حقل أو نطاق عملاء جديدًا داخل API التقرير.
منحة التقرير نفسها تسمح بقراءة تعريفات الاشتراك وفق مرشح صحيح، ولا يغير
إخفاء المرشح ذلك العقد.

يجب إلغاء القراءة والمراقبة وتجهيز الطباعة عند انتهاء المنحة أو السياق،
وتصفير التقرير والعميل والأقسام القديمة، وحجب المضيف المطبوع نفسه عبر
مالك ReportPage. تُغلق قائمة العميل المنفصلة؛ يُعاد فحص الوصول في كل
معالج، حتى قبل عمل المؤثرات. يُربط إخراج التقرير بالسياق ومتطلبات المرشح
المطبق؛ لا ينشر رد قديم ولا يعيد منحه إحياء طلب ملغى. يظل bootstrap
والمراقبة والتحديث الصامت بمالكيها القائمين، دون تكرار التقارير عند تغيّر
منحة غير مرتبطة.

الأدلة الفعلية: مكوّن التقرير ومساره وخدمته و`LimousineTariffController`
والمفتاح المراجع. مرجع سبيد شاشة `16-limousine/04-tariff-report`،
والمتحكم `C0902` من لقطة ٢٨ أكتوبر؛ يثبت العميل والأقسام، ولا يقرر
مفاتيح سيجما أو صلاحيات الخادم. يتتبع العامل شرح المرجع الأصلي قبل
التنفيذ ويسجل أي غياب. لا حاجة لمثال أودو لتغيير العقد المحلي المثبت.

الجذر يملك registry وtsconfig والجرد والدليل والتكامل. العامل يملك مجلد
`Limousine/limousineTariffReport` فقط وسجل تسليمه. الفحص مصدري، مع
بقاء البناء والاختبارات والتشغيل والقياس وقبول المالك معلقًا.
