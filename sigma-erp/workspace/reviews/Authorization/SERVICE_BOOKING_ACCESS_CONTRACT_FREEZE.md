## المسار والأفعال الموجودة

المسار الفعلي قائمة بحوار محرر رأس وبنود صغيرة، وحوار سجل قراءة مستقل.
لا توجد مسارات محرر مستقلة أو aliases في ملف المسار الحالي، ولا إجراء
حذف أو إلغاء أو طباعة في واجهة هذه الوحدة. إجراءات المرجع غير الموجودة
تظل فجوات وظيفية مسجلة، ولا ينشئ تبني الوصول endpoints أو منحًا لها.

| السطح والطلب | المتطلب |
|---|---|
| القائمة والرابط والبحث والفرز والترقيم | VehicleServiceBooking.View |
| إنشاء الحجز | العرض مع VehicleServiceBooking.Create وVehicleServiceBooking.AgreementOptions وServiceItem.Lookup |
| تعديل الحجز المعلق | العرض مع VehicleServiceBooking.Update والاختيارات السابقة، وحالة Pending المثبتة |
| اعتماد المعلق | العرض مع VehicleServiceBooking.Confirm وحالة Pending/canConfirm |
| إغلاق المعتمد | العرض مع VehicleServiceBooking.Close وحالة Confirmed/canClose |
| سجل التغييرات | العرض مع VehicleServiceBooking.History؛ لا يتطلب إذن تعديل الحجز |
| تصدير كامل النتيجة | العرض مع VehicleServiceBooking.Export، والمرشح المطبق المنقح عند التنفيذ |
| مرشح العميل | العرض مع Customer.Lookup؛ اختيار اختياري لا يحجب القائمة عند غياب منحته |

تأتي الأفعال من خدمة VehicleServiceBookingsService والمتحكم
VehicleServiceBookingController. منح custom أعلاه موجودة فعلًا في
ReviewedPermissionOperations؛ يحل الخادم CRUD الموروث بنفس المفتاح.
تظل Closed نهائية، ولا يضاف Cancel من حقل CancellationReason وحده.
كل تغيير اختيار/ملاحظات بند داخل المسودة تابع لحفظ التجميع.

## ملكية الشركة والفروع

يرتبط الحجز بـVehicleId محفوظ يحدده الخادم من الاتفاق المختار؛ تستخدم
القائمة والتفاصيل المركبة نفسها لعرض اللوحة. يعتمد نطاق هذه الشريحة
ملكية الفرع الموروثة من Vehicle.BranchId، كما يملك الاتفاق القائم فرعه
من المركبة. يضاف النوع الرئيسي إلى BranchScopeRegistry بمسار ذي حافتين
حقيقيتين، دون حقل فرع مخترع أو تغيير schema.

يشمل النطاق القائمة والتصدير والتفاصيل والسجل والاعتماد والإغلاق؛ يثبت
السجل وجود رأس قابل للقراءة قبل قراءة صفوفه. لا متحكم مستقل للبنود أو
التاريخ؛ كلاهما يقرأ ويكتب عبر الرأس فقط، وتُراجع هذه الحقيقة قبل التسليم.
تتحقق حراسة الحفظ من VehicleId الأصلي والجديد وفروعهما، بما في ذلك
حجز أعيد إسناده لاتفاق آخر. تغيير الحجز ليس تحويل المركبة ذاتها، ولا
يضاف له تصريح تحويل فرع. الحجز موعد إداري، والتنفيذ الفعلي في شغل/سجل
الخدمة وحدة أخرى؛ لا يدعي العقد لقطة فرع تاريخية غير موجودة أو قيدًا ماليًا.

فحص تكرار الموعد وتوليد رقمه يظلان على مستوى الشركة كلها. يجب ألا يخفي
فلتر فرع مصدرًا منافسًا أو أعلى تسلسل، لذلك تبقى قراءتاهما بلا فلاتر
الفروع مع SubscriptionId الصريح وفلاتر الحذف المقصودة، دون إخراج صفوف
الفروع الأخرى للعميل. لا هجرة ولا snapshot ولا index جديد. تبقى معالجة
تعارض التزامن عند SaveChanges والفهارس الفريدة القائمة.

## العمر والتحميل والمصادر

تُربط القراءات والاختيارات والقرارات بالمنحة والسياق ويُعاد فحص عضوية
الصف وحالته وهويته بعد الإقرار وقبل الكتابة. تُخفى وتُعطّل المضيفات
المحمية دون هدم محرر المسودة؛ يبقى حوار المحرر والسجل خارج المضيف
المحجوب وتخضع منافذهما لمالك EditorDialog. يملك الوالد CanDeactivate
للمحرر، وتلغى قرارات قديمة مع الاحتفاظ بتخلص محلي صريح بعد الرفض.

الحفظ والاعتماد والإغلاق المرسلة مستقلة عن إلغاء القراءة، مع سياج نشر
محلي وعالمي عبر HttpContext. يثبت نجاح حفظ المحرر قبل سياج النتيجة ولا
يعاد تلقائيًا. يجب ألا يعيد callback قديم تحميل قائمة سياق جديد.

القائمة والتصدير لهم محمل الصفحة. التفاصيل وقراءة السجل وتهيئة محرر
body dialog لهم StateMessage محلي واحد وaria-busy وRetry. الحفظ
والانتقالات يحتفظان بمالك الكتابة القائم مع تقدم الحوار المشترك.

Customer/GetSelect مصدر cacheSelect متبنٍ: bootstrap محدود ثم مراقبة
المصدر عبر ReferenceLookupBindings وإبطال Customer الحالي. AgreementOptions
تشغيلي مباشر، وServiceItem/GetSelect مرجعي مباشر بلا opt-in. لا مخبأ
حجوزات جديد. سحب اختيار العميل يلغي قراءته ومراقبه ويزيل raw/applied
customerId قبل البحث والتصدير؛ تغير باقي المنح لا يعيد القراءة التشغيلية
أو يستبدل مسودة. يفصل نجاح bootstrap عن انتظار التحميل والخطأ وإعادة المنح.

## الأدلة والحدود الوظيفية

قُرئت شاشة 08-fleet/16-service-bookings من لقطة ٢٨ أكتوبر وكود محرر
C1205. لم يُعثر في catalog مكتبة ٢٧ أكتوبر على شرح أصلي مستقل لحجز
الخدمة، فلا يُدّعى وجوده؛ S179/S229/S253 تخص البند/التعريف/سجل التنفيذ
وليست دليلًا بديلًا لهذه الشاشة. يُستكمل كود القائمة C1206 والسجل C1207
ضمن شريحتيهما. المرجع يعرض الإنشاء والتعديل والملاحظات والحذف والإلغاء
والاعتماد والإغلاق والسجل والتصدير؛ سيجما يدعم المجموعة المجردة أعلاه.
فصل الموعد عن التنفيذ تؤيده وثيقة Odoo Fleet/services المحلية المقروءة
بعد سبيد، ولا تثبت وثيقة Odoo صلاحيات سيجما أو ملكية الفرع أو ماليته.

المرجع يدعم مجالات المرشح والقائمة؛ لا تغيير أسماء أعمدة ListVM أو
Filter/paging/sort/count أو قواعد الوقت والملاحظات والعداد الصحيحة
بعقدها الحالي. التحقق المالي وبيانات مخطط جديدة غير مطلوبة لهذا التبني.
لا تُخترع أدوار حرفية أو منح ضمنية من عنوان/أيقونة.

## الملكية والتسليم

الجذر يملك backend branch registry والخدمة، ومفاتيح الوصول وservice
transport وroute registry وملف المسار والتوثيق والجرد ودليل المستخدم.
عامل القائمة يملك components/list/** وcomponents/history/** فقط،
وعامل المحرر يملك components/editor/** فقط. لا تداخل، مع تسليم مصدرّي
ومراجعة جذرية قبل ترقية الجرد. يجب إعادة مطابقة الفلاتر وعدد السجلات
والاختيارات والتقدم والمواصفات والدليل، وتبقى بيانات SQL/الزمن والتشغيل
للمالك. لا build/tests/lint/browser/DB/migrations/snapshots/commit/push/deploy.

## توضيح التكامل — حالة الانتقال والتزامن

وجد تتبع الانتقالات أن الخدمة تلتقط DbUpdateConcurrencyException، لكن
Status لم يكن concurrency token؛ كان تأكيد قديم يستطيع الكتابة فوق
إغلاق أحدث إذا استقر VehicleId نفسه. تضيف الشريحة metadata التزامن
للحالة الموجودة دون عمود أو فهرس جديد، مع إبقاء رسالة تعارض الحالة عند
مالك الخدمة. لا تُنشأ هجرة أو يُعدل snapshot؛ التغيير يؤثر شروط UPDATE
فقط. أضيفت أربع مواصفات مصدرية في BranchDataScopeTests لقراءة الحجز
حسب مركبته، وفرع الأصل عند إعادة الإسناد، ومنع كتابة صاحب عرض فقط،
ورفض حالة قديمة متزامنة. لم تُشغّل هذه المواصفات.
