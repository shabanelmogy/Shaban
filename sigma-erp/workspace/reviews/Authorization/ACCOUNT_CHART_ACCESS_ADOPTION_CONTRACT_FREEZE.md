| التحقق | source-only؛ لا build/test/lint/browser/DB/migration/snapshot/commit |

## القرار والمصادر

الشاشة هي UI04 hierarchy tree workspace: الشجرة تقرأ عملية مخصصة، والمحرر
المركب يقرأ تفاصيل الحساب واختيارات التصنيف ومراكز التكلفة، ثم ينفذ إنشاءً أو
تعديلًا أو حذفًا. التحويل إلى مجموعة وتهيئة التصنيف أحداث منفصلة ولا تُستنتج
من ظهور زر أو من صلاحية العرض.

قُرئ شرح Speed للشجرة `01-chart-of-accounts.md` وكود الدورة المؤرخ C0481/C0482
بتاريخ 2026-10-28، ثم قورن بالمصدر الحالي. Speed يثبت استعراض الشجرة وفتح
المحرر والحفظ والحذف والتحويل والتهيئة؛ لا يثبت مفاتيح Sigma أو إنفاذ الخادم.
لا توجد فجوة تحتاج Odoo لهذه الدفعة.

## مفاتيح الطلبات والأحداث

| المسار/الحدث | المتطلب المصدرّي |
|---|---|
| route/tree | `Account.GetAccountNestedList` |
| تفاصيل الحساب واختياراته | `Account.View` + `AccountTypeDefinition.GetOptions` + `CostCenter.Lookup` |
| إنشاء حساب فرعي | تفاصيل القراءة + `Account.Create` |
| تعديل حساب | تفاصيل القراءة + `Account.Update` |
| حذف حساب | `Account.View` + `Account.Delete` |
| التحويل إلى مجموعة | `Account.GetAccountNestedList` + `Account.ConvertToGroup` |
| تهيئة التصنيف | `Account.GetAccountNestedList` + `AccountTypeDefinition.Initialize` |

لا تُضاف صلاحية عامة باسم الشاشة، ولا يُفتح `/Account` بـ`Account.View` وحدها.
يبقى زر الإضافة محكومًا بحالة الشجرة، ويظل زر التحويل محكومًا بحالة الحساب
والمتطلب المستقل. خادم Sigma هو حد الإنفاذ النهائي لكل الطلبات.

## العمر والحالات

قراءة الشجرة وقراءات التفاصيل والاختيارات تُلغى عند سحب متطلب القراءة أو تغير
السياق، ولا تنشر نتيجة قديمة. الكتابات المرسلة لا تُلغى تلقائيًا؛ لا تعاد
إرسالها عند إعادة المنح. المحرر يحافظ على المسودة عند سحب القراءة ويخفي السطح
المركب، مع تأكيد مغادرة مؤجل يعيد فحص الهوية والسياق والمنحة.

## الفجوات والاستبعاد

التصدير القديم، حالة التفعيل القديمة، وتفاصيل إعدادات Speed غير الموجودة في
عقد Sigma الحالي لا تتحول إلى أحداث أو مفاتيح مخترعة. تغيير بنية الحساب أو
حساباته المالية خارج هذه الدفعة.
