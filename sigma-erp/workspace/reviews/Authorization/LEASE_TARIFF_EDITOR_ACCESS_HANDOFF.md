## دورة الوصول والسياق

- يلتقط المحرر سياق الممثل عند الفتح؛ لا يعرض سياقًا جديدًا أو يطبق استجابة قراءة قديمة بعد تغيره.
- المضيف يبقى مركبًا ويصير `hidden` و`inert` عند الحجب؛ النموذج المعطل يحمي عناصر الإدخال والقوائم/التقويمات المضافة إلى body، وMockData يحمل متطلب القراءة أو متطلب الكتابة الحالي.
- تأكيدات إزالة الصفوف تنتهي عند سحب منحة الكتابة. تأكيد تجاهل المسودة ينتهي عند السحب بعد فتحه؛ ويظل مسار التجاهل المحلي الجديد منفصلًا عن كتابة الأعمال.
- لا تحمل الكتابة المرسلة `takeUntilDestroyed`. تمر `POST`/`PUT` بسياق `CAN_PRESENT_API_OUTCOME`، ولا تنشر نتيجة قديمة محليًا أو عالميًا. تسجل `saveCompleted` النجاح أولًا لمنع إرسال حفظ ناجح مكرر.

## نطاق ثابت

- لم تتغير الحسابات أو DTOs أو حقول/دقة التعرفة والصفوف أو حمولات الإنشاء والتحديث.
- لا تغيير لخدمة إعدادات الفروع المشتركة أو الخلفية أو المخطط أو migrations.
- قبول المالك التشغيلي مطلوب: إنشاء ثم تحديث، منحة Create فقط ومنحة Update فقط، سحب القراءة/الكتابة والمحرر أو تأكيد الإزالة مفتوح، إعادة المنح بعد إلغاء القراءة، وإتمام حفظ مرسل بعد السحب.
