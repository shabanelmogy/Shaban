# مطابقة صلاحيات تعريفات الموظفين وطلبات العملاء

| البند | القيمة |
|---|---|
| Status | Implemented — source-only |
| Owner verification pending | yes |
| العقد | [صلاحيات تعريفات الموظفين وطلبات العملاء](STAFF_DEFINITIONS_CUSTOMER_REQUESTS_ACCESS_CONTRACT_FREEZE.md) |

| الشاشة | العرض والمخرجات القائمة | الأفعال ومتطلبات المحرر |
|---|---|---|
| الأقسام | القائمة والبحث والتفاصيل | إضافة وتعديل وحذف بمفاتيح `Department` |
| الأدوار الوظيفية | القائمة والبحث والتفاصيل | إضافة وتعديل وحذف بمفاتيح `StaffRole` |
| المسميات | القائمة والبحث والتفاصيل وتصدير كل النتائج المطابقة | إضافة وتعديل وحذف بمفاتيح `StaffDesignation` |
| أنواع الإجازات | القائمة والتفاصيل والمعتمدون المحفوظون والتصدير | إضافة وتعديل مع `Staff.Lookup`، وحذف مستقل. تشمل الحراسة روابط الحوارات ومعاملات المسار وتغييرات صفوف المعتمدين |
| طلبات العملاء | القائمة والتفاصيل والتصدير. مرشح العميل اختياري بمنحة `Customer.Lookup` | إضافة وتعديل مع اختيار العملاء، وحذف وإغلاق الطلب المفتوح بمفتاحين مستقلين |

تربط سياسة المسارات القوائم بقائمة التنقل وتؤمّن روابط محررات أنواع
الإجازات. تستخدم القوائم والمحررات مالك جلسة التعريفات؛ يستمر فحص منحة
الخادم عبر محلل نقاط الخدمة العام. يطابق مسار الإغلاق
`POST /CustomerRequest/{id}/Close` المفتاح المراجع `CustomerRequest.Close`.
يظل انتقال الحالة تحت مالك الإغلاق في الخدمة.

يتولى محمّل الصفحة قراءات القوائم والتصدير وتهيئة مرشح العميل. تعرض
الحوارات قراءاتها محليًا. القوائم والتفاصيل قراءات مباشرة، واختيار موظفي
الاعتماد مباشر. يربط اختيار العميل القراءة الأولية بالمراقبة اللاحقة عبر
ذاكرة الاختيارات المشتركة. يؤدي سحب منحة اختيار العميل إلى إزالة مرشحه
وإعادة قراءة القائمة حسب المنح الباقية. تبقى المسودة في محررها، وتُلغى
القراءات وتأكيدات الكتابة المعلقة عند فقد الوصول. يحتفظ الطلب المرسل
بعمره، وتُحجب نتيجته بعد فقد صلاحية سياقه.

تطابق الإجراءات القائمة شرح المسميات في سبيد ومتحكمات القوائم والحوارات
المذكورة في العقد. جاء الفصل بين اختيار المرجع والعرض ومنحة الإغلاق
من نقاط الخدمة في Sigma. حُدثت الموضوعات الخمسة في الدليل داخل التطبيق.
تستعمل الدفعة الاستعلامات والترقيم الحاليين من دون تغيير المخطط أو
إضافة استعلام صفّي. تبقى قياسات زمن القراءة والتحقق من خطط الاستعلام
ضمن قبول التشغيل.

نجحت فحوص صياغة TypeScript وقوالب Angular وحل الاستيرادات المحلية،
ومطابقة المنح القابلة للإسناد والجرد، وفحص الفروق والوصفات ومراجع الكتب.

يشمل قبول المالك تجربة العرض فقط، والمنح المستقلة، والروابط المباشرة
لأنواع الإجازات، وسحب منحة الاختيار مع محرر مفتوح، وسحب الإغلاق قبل
التأكيد، وتبديل السياق مع كتابة مرسلة. البناء والاختبارات والتشغيل
وقاعدة البيانات ضمن القبول المعلق.
