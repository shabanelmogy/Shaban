  تحميل خيارات صحيحة.

## ملاحظات المطابقة والقبول

طلب فحص رصيد المخزون وكمية النقل وقفل الكتابة غير منطبق على تبويبي الإعدادات العامة والرسوم؛ لا ينشئ أي منهما حركة مخزون. ليست القائمة المجمعة للإعدادات تقريرًا ماليًا أو Excel، وتبقى أحكام تصفية/تصدير القوائم الوظيفية لدى الوحدات المالكة لها. لا يجوز تعميم أي استثناء مرجع غير نشط أو سياسة فرع من شاشات المخزون على إعدادات الشركة تلقائيًا.

**القرار حُسم:** تبويبات أسرار API والهوية وبوابات الدفع والاعتماد والترقيم وبقية `/Settings` لمدير الاشتراك وحده. هذا القرار لا يمس حقوق تنفيذ الاعتمادات الأصلية من مستنداتها، أو قراءات الضرائب وخيارات الدفع والمستندات المشتركة للمستخدم العادي؛ حقوق تلك العمليات مستقلة. يصنف الجرد `kind: admin-only`، وتخضع ترقية مستوى الإثبات `status` لإغلاق تدقيق الخادم والعمليات، وليس لإزالة قرار معلق.

**حالات القبول التشغيلي المطلوب إجراؤها:** مستخدم مدير ومستخدم عادي يحمل منح `ChargeSettings.Get/Update` فقط؛ سحب المدير خلال قراءة وخلال حفظ مرسل؛ إلغاء أو قبول تجاهل مسودة؛ عودة الوصول لنفس المالك؛ تبدل الشركة أو المستخدم؛ غياب اختيارات طرق الدفع؛ منع تكرار POST بعد عودة الوصول؛ وفحص واجهة الهاتف وRTL ونتائج HTTP الحقيقية. تُسجل نتائج البناء/اختبارات المصدر للمرحلة في تقرير الإغلاق التالي؛ لا يُدّعى تنفيذ اختبار قاعدة خارجية أو متصفح هنا.

**نتائج التحقق بعد قرار المالك:** مصدر الخادم بُني بنجاح عبر `dotnet build SiGma.ServerAPI/SiGma.ServerAPI.csproj --no-restore -v quiet`، ومشروع اختبارات `SiGma.BranchAccess.Tests` بُني بنجاح؛ اختبار `SettingsWorkspaceAdminEndpointTests` نجح **70/70**، وتشمل حالاته مخرجات مرشح الصلاحية الفعلية 403 مقابل مرور المدير (بقاعدة InMemory)، وإعلان operations إدارية غير قابلة للمنح، وحجب `WebBookingApiKey/GoogleApiKey` عن غير المدير، والإبقاء على `GetMySetting` والعمليات التشغيلية المستقلة. نجح فحص TypeScript للواجهة، و`git diff --check` للمستودعين وrecipe drift check. أول محاولة لبناء Angular development فشلت بسبب نفاد ذاكرة Windows الافتراضية في `esbuild` (`VirtualAlloc errno=1455`)، ثم **نجحت المحاولة الثانية** بتقليل التوازي (`GOMAXPROCS=2`, `NG_BUILD_MAX_WORKERS=2`) وزمن 128.815 ثانية و`exit code 0` بتاريخ `2026-11-13T21:41:34.128Z`. يظل تنفيذ HTTP حي ومتصفح وقاعدة بيانات خارج التحقق المسجل.

**حدود الإغلاق:** `/Settings` وجميع أبنائه `TenantAdmin` في الملاحة، وعمليات HTTP الإدارية الحصرية المذكورة أعلاه مقيّدة في المصدر؛ لا يثبت ذلك منع المستخدم العادي من **نفس** واجهات `SettingsHolidayModel` و`HrmSetting` الشرعية المشتركة مع `/Holiday` و`/HrmSetting` خارج مساحة الإدارة. كذلك كشف الجرد مصدر `fines` في الواجهة بلا `FinesController` مطابق ومرجعًا لتحديث قائمة الهوية الوطنية لا يطابق إجراءً ظاهرًا في controller؛ لم تُخترع لهما API جديدة ضمن قرار الصلاحيات. لا تُرقّى حالة جرد 169 إلى `operation-confirmed` دون مطابقة كاملة لتبويباته وHTTP الحي.
