# SalesQuotation access contract — freeze 2026-11-12

المورد `SalesQuotation`، والمسارات `/SalesQuotation`, `/create`, `/view/:id`, `/edit/:id`, `/details/:id`. **Create-only بلا `SalesQuotation.View` ولا list GET.** القائمة وExcel والتفاصيل والطباعة تستلزم `SalesQuotation.View`، بينما customer filter/grid يستلزم `Customer.Lookup` إضافية شرطًا؛ تعرض الحقول غير المحمية تاريخيًا فقط دون leak أسماء Partner خارج scope. Create requires `SalesQuotation.Create` + `Customer.Lookup` + `CarModel.Lookup`; Edit requires `SalesQuotation.View` + `SalesQuotation.Update` مع lookup نفسها. معاينة الضريبة `SettingsCommonModel.GetMySetting` اختيارية، ولا تمنع Create-only؛ عند فقد المنحة fallback معاينة فقط.

ستة قرارات مستقلة بخادم التنفيذ: `SalesQuotation.InternallyApprove`, `InternallyReject`, `CustomerApprove`, `CustomerReject`, `Revise`, `Unapprove`، ولكل منها prerequisite `SalesQuotation.View`؛ تمر على حالة المستند القانونية/الانتهاء، وتُحجب من قائمة الأفعال إذا غابت الصلاحية أو حالة الخادم. `SalesQuotation.Delete` يتطلب View. `SalesQuotation.GenerateDownPaymentReceipt` يحتاج View وينجح فقط عند حالة المصدر/مبلغ المقدم وعدم وجود إيصال حي؛ واجهة الإيصال الفعلية تحتاج أيضًا `Receipt.Create` و`Receipt.QuotationContext`. `SalesAgreement.Create/View` منفصلان عند فتح عقد من العرض.

`SalesQuotation` root مشترك داخل tenant (لا branch execution محفوظ)، لكن العملاء وأكوادهم، linked SalesAgreement/Receipt IDs والملحقات مرئية فقط إذا كانت السجلات المرجعية في tenant/branches المسموح بها. Write validation يستخدم customer scoped active، model scoped active، وlinked locks لا تتجاهل مستندًا حيًا مخفيًا بفرع آخر. 404 للـroot المخفي/المفقود، 405 لكل generic unsupported + nonassignable metadata. لا `IgnoreQueryFilters` على root لقارئ عادي؛ استعماله فقط لفحص link locks مع tenant مثبت وعدم نشر هوية الصف المخفي.

الحارس Angular يراجع `AccessViewPolicyService`, `AuthService`, `ReferenceLookupCacheService`, actor/session/branch grant revisions: لا طلب قراءة دون grant؛ responses/Excel/print القديمة تُلغى ولا تظهر بعد revoke. POST/PUT/DELETE/decision بعد الإرسال تستكمل في الخادم ولا تُلغى بتدمير المكون، مع `CAN_PRESENT_API_OUTCOME` لنشر النتيجة في الجلسة الأصلية وحدها. التوثيق واختبارات المصدر لا تُعد قبولًا تشغيليًا؛ لا build/tests/lint/typecheck/browser/DB/migration/snapshot/commit/push/deploy.
