# عقد صلاحيات تعرفة الليموزين

| البند | القيمة |
|---|---|
| Status | Frozen |
| Owner verification pending | yes |
| النطاق | مسار `/LimousineTariff` ومحرر النطاق الأساسي والشركات وطلباته الفعلية |
| التاريخ | ٩ نوفمبر ٢٠٢٦ |

الواجهة مساحة عمل إعدادات ذات مجموعات قابلة للتحرير، وليست قائمة CRUD.
العقد القائم يحفظ لقطة كاملة للنطاق، بما يشمل الإضافة والتعديل وإزالة الصفوف
الغائبة. منحة الحفظ الفعلية `LimousineTariff.EditList`؛ لا تقسيم مصطنع
للحفظ إلى منح إنشاء وتعديل وحذف عامة.

| السطح | المتطلب المثبت من المصدر |
|---|---|
| القائمة والرابط المباشر وقراءة النطاق الأساسي | `LimousineTariff.GetTariffs` و`Location.Lookup` و`VehicleType.Lookup` و`Currency.GetFinancialNumberPolicy` |
| تبويب الشركات واختيار العميل وقراءة نطاقه | المتطلبات الأساسية وإضافة `Customer.Lookup` |
| تغيير السعر وإضافة صف وإزالته وحفظ اللقطة | متطلبات قراءة النطاق الحالي وإضافة `LimousineTariff.EditList` |
| تغيير التبويب أو العميل لمستخدم عرض فقط | قراءة النطاق الوجهة، دون منح الكتابة |

تُحمّل الاختيارات المطلوبة فقط عندما تسمح متطلبات النطاق بها. يبقى استهلاك
سياسة المال ومالكي المخازن والمراقبة القائمين دون تخزين تشغيلي جديد.
تُلغى القراءات والتأكيدات المنتهية بالسياق أو سحب المنحة، ويُعاد فحص الوصول
بعد القرار. تُحفظ المسودة المحملة وتُحجب عن السياق الجديد، ويظل التخلص المحلي
متاحًا. تُغلق منافذ الاختيارات المنفصلة. الحفظ المرسل مستقل، مع سياج نشر
محلي وعالمي عبر سياق HTTP، ودون إعادة إرسال تلقائية أو تكرار نجاح منتهي السياق.

يتحقق الخادم من المفاتيح بواسطة محلل نقاط النهاية والفلتر المشترك ومن
الاشتراك الحالي داخل الخدمة والمستودع. التعريفات مشتركة داخل الشركة؛ لا
إسناد فرع أو تغيير مخطط في هذه الشريحة. تظل نقاط `AddList` والحساب الفعال
ذات منح مستقلة، والتقرير مسارًا مستقلًا يحتاج شريحته الخاصة.

الأدلة: مسار سيجما والمحرر والخدمة و`LimousineTariffController` وعمليات
الخادم المراجعة؛ شرح سبيد `S117/S121/S123` والكود `R0230/C0910` من
لقطة ٢٨ أكتوبر، كما تتبّعها عامل الاستكشاف وراجع الجذر ربط الشاشة.
مرجع سبيد الأوسع لمصفوفة أنواع الرحلات مسجل مسبقًا في مراجعة الليموزين
كفجوة وظيفية؛ لا يغير عقد الحفظ القديم أو مفاتيح صلاحياته في هذه الدفعة.
أودو لا يقدم عقدًا محليًا لهذا المحرر، فلا يتغير سلوك التسعير بمثال خارجي.

الجذر يملك المسارات العامة والجرد والدليل والتكامل. العامل يملك مجلد
`Limousine/limousineTariff` فقط مع سجل تسليمه. الفحص مصدري؛ البناء
والاختبارات والتشغيل والبيانات والقياس معلقون للمالك وفق الحدود الحالية.
