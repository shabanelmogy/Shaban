## الموجود والأثر

تستهلك هذه الخطة [المراجعة والأدلة المرجعية](TRANSPORTATION_MODULE_FEATURE_REVIEW.md). جرد سبيد مؤرخ ٢٨ أكتوبر يثبت الإنشاء والإغلاق المؤرخ وإجراءات إنهاء الرحلات وتعديلها، لكنه لا يكشف قواعد الخادم أو دورة الفوترة. شرح ٢٧ أكتوبر لا يقدم فصل نقل مطابقًا؛ لا تُستورد قواعد الليموزين. تحفظ عقود الاتفاقية السابقة، مع تعديل الشريحة الحالية الصريح فقط.

فحص المصدر إلزامي الآن؛ البناء والاختبارات والمتصفح وقاعدة البيانات تبقى عند المالك. لا تنفذ migrations أو تعدل snapshots. الترحيل المقترح بعد مراجعة المالك: `PreserveTransportationTripDatesAndQuantityPrecision` لإضافة تاريخ nullable ودقة كمية بند المعاملة. يراجع المالك بياناته ونسخة احتياطية قبل التطبيق؛ لا استخراج تاريخ مفقود من التدقيق. ترتيب النشر: المخطط المتوافق أولًا ثم الخادم والواجهة؛ استمرار fallback يحفظ قراءة القديم. الرجوع يقتضي حفظ عمود التاريخ ودقة البيانات بدل إسقاطهما تلقائيًا.

معايير المصدر: لا عرض/توليد طفل محذوف، لا رحلة مجدولة قبل البداية، لا FK خارج المستأجر، مرشحات الكشف نفسها للشاشة/التصدير/الطباعة، رفض كمية فوق6 منازل دون تقريب المدخل، لا callback قديم يؤثر على جلسة جديدة، bootstrap finite مع failure/Retry ومراقبة منفصلة، ومالك تقدم مرئي واحد. القياسات وخطط SQL ومصفوفة الأحجام/RTL/الثيمين الواردة في المراجعة pending للمالك. لا تحول هذه الخطة نتيجة source-only إلى ادعاء تشغيل.
