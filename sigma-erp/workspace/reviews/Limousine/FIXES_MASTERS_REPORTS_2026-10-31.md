## المصدر والمراجع

قُرئت تعليمات مساحة العمل والمهارة والخطة والتقارير السابقة. المقارنة المرجعية المفصلة وبصمات الشروح والمتحكمات محفوظة في سجلي المراجعة `REVIEW_2026-10-31_MASTERS.md` و`REVIEW_2026-10-31_REPORTS.md`؛ لم يتغير الدليل المرجعي أو تُنفذ شيفرته. شكل المواقع والأنواع والتفضيلات هو القائمة مع حوار النوع 01، والتقارير النوع 07، والتعريفة استثناء مساحة تحرير لقطة كاملة. قورنت قائمة أعمال الورشة وواجهة كشف حساب العميل كمرجعي التركيب، وعقود `EditorDialog`, `ReferenceLookupStatus`, `ReferenceLookupBindings`, `FinancialNumberPolicyService`, `DataTable` و`ReportPrintSession` الفعلية. الكتل المالكة: UI2/13/19/21/22/28، مع UI1/6/20/29 للشكل والمخرجات. لم تنشأ قاعدة عامة أو مالك مشترك جديد، فلا تعديل كتب أو مهارة أو حزم مشتقة بهذه الشريحة.

## ما نُفذ

| الجزء | التغيير النهائي والأثر |
|---|---|
| محرر التعريفة | أضيفت قراءة محدودة ناجحة لسياسة المال من المالك الحالي، مع تحقق المظروف ودقة العملة والتوافق مع التخزين. السعر يقبل قيمة مالية كسرية ويستعمل `financialScaleValidator` و`finiteNumberValidator` و`decimalStep`؛ أزيل مدقق الصحيح وحده وأزيل حد Int32. لا `maxFractionDigits` يقص المدخل إلى دقة السياسة: توجيه الإدخال الحالي يترك المدخل ثم يرفض المقياس الزائد. تعاد صلاحية السعر عند وصول السياسة دون تغيير القيم أو dirty |
| كاش العميل بالتعريفة | تبقى المصادر غير المعتمدة للموقع ونوع المركبة مباشرة. يبدأ watch العميل المعتمد مرة بعد نجاح finite bootstrap؛ يستخدم selected/current getters و`disableRetainedOptions=true` والاختيار يدعم optionDisabled. تحديث المصفوفة المرجعية لا يكتب قيم النماذج أو الأسعار |
| تهيئة التعريفة | دفعة `forkJoin` تتحقق من فشل النقل/المظروف والإكمال بلا قيمة، وتبقى readiness=false مع Retry. `ReferenceLookupStatus` يملك تهيئة الصفحة؛ أزيل مؤشر `StateMessage` المحلي المكرر. تبقى قراءة التعريفة والحفظ على عداد الصفحة المتوازن |
| سياق التعريفة | الإشعار المشترك يبطل الجلسة، يلغي القراءة وwatch، ويمسح الصفوف والأسماء والعميل ويعطل النماذج حتى إعادة فتح المسار. التأكيدات والحفظ تحت revision؛ لا يلغى حفظ مرسل عند تغير السياق ولا يعيد رده القديم قراءة أو استعادة نموذج |
| تقارير التعريفة والاستخدام | اكتمل فصل finite bootstrap عن watch للعملاء والفروع المعتمدة، ومعالجة الإكمال الفارغ وفشل القناتين وRetry، ومالك التحميل المرجعي بالصفحة. عند تغير السياق تمسح الاختيارات والنتائج والفلاتر، وتبقى إعادة تهيئة المراجع متاحة صراحة بدل readiness=false بلا Retry. تلغى قراءة التقرير وتحضير الطباعة ولا تعود نتائج قديمة |
| تقرير التعريفة | السعر في الجدول والتصدير يستخدم نوع money المشترك، وأزيل التحميل النصي المكرر مع عداد الصفحة |
| تقرير الاستخدام | بطاقة المسافة تعرض حتى `QUANTITY_DECIMAL_PLACES` الست منازل. عمود الجدول type:number يحافظ على القيمة العددية الكاملة كما يدعم مالكه الفعلي؛ لم يُضف input/خاصية غير مدعومة إلى عقد DataTableColumn. بعد توجيه المالك باستعمال الأقرب الصحيح دون أسئلة، ثبّت الجذر حد ٣٦٦ يومًا ونسقه مع الخلفية؛ أضيف validator لفارق أيام التقويم ورسالة shared FieldError، دون قص صفوف النتيجة |
| تقرير التخصيص الإجباري | سياج السياق يلغي القراءة وتحضير الطباعة ويمسح التقرير. بعد تجميد الجذر لسجل التعيين الصريح، أضيف وقت التعيين ومنفّذه إلى نموذج الصف وأعمدة الجدول والتصدير/الطباعة المشتركة، مع بقية تفاصيل الرحلة. مصدر السائق والسبب الحدث المحفوظ وليس Notes؛ تاريخ الفلتر هو وقت التعيين. لا تستنتج أحداث إجبار تاريخية من السجلات العادية |
| قوائم المواقع والأنواع والتفضيلات | قراءات القائمة قابلة لإلغاء السياق داخل switchMap مع بقاء trigger الخارجي حيًا. تمسح الصفوف والعدد والمرشحات. تأكيد الحذف يلتقط revision فلا يستطيع تأكيد قديم تنفيذ هوية سياق جديد، ورد الكتابة القديم لا يغير الصفحات أو يعيد القراءة |
| محررات المواقع والأنواع وإعداد النوع والتفضيلات | الإشعار يمسح النماذج والأسماء ويبطل الجلسة ويوقف القراءات ويمنع إعادة المحاولة بالهوية القديمة؛ يمكن إغلاق الجلسة بعد انتهاء الكتابة وإعادة فتحها. نجاح/فشل حفظ مرسل سابقًا لا يستعيد نموذجًا ولا يرسل saved/changed للجلسة الجديدة. قراءات هذه الحوارات body-appended تستخدم `StateMessage` المحلي القائم وأزيل عداد الصفحة المحجوب خلفها؛ الحفظ يبقى عامًّا |
| بحث المواقع | يبقى طلب بحث مباشر غير مخزن، ويلغى عند تغير السياق؛ تصفير trigger يلغي أيضًا المؤقت السابق. للمسار مؤشر حالة محلي مشترك مع الخطأ وRetry |
| تصدير تفضيلات الجدول | يلتقط filter snapshot قبل `fetchAllPages`، ويبدأ عداد الصفحة وينهيه في finalize، ويلغي العملية كاملة عند تغير السياق أو التدمير. لا تغيير لعقد اكتمال الصفحات أو شكل الأعمدة |

## مطابقة بوابات المصدر

المصادر المعتمدة التي تغير استهلاكها: `Customer/GetSelect` و`Branch/GetSelect` من `environment.baseUrl`، بمظروف `Results<DropDownSelect>` ومراقبة مالك المصدر الحالي. المصدران يحتفظان بإبطال الكتّاب وموضوعات التحديث الحالية؛ لا socket أو cache جديد. `Location/GetSelect` و`VehicleType/GetSelect` مباشران لعدم opt-in. سياسة المال `Currency/GetFinancialNumberPolicy` تبقى من مالك السياسة ولا تُضاف إلى كاش المراجع. التقارير والقراءات التشغيلية والتوافر ليست مصادر كاش.

للودر: لا يوجد تعطيل `showPageLoading` بالمسارات المذكورة؛ المضيف الافتراضي في shell يبقى صاحب الصفحة. قراءات الحوارات التي يخفي overlay المضيف العام تستعمل المؤشر المحلي القائم. `[loading]` على DataTable/PrimaryActionButton لا يعد مؤشرًا ثانيًا لأن المالكين يخفيانه عند global. لم تُحذف busy/disabled/error/Retry للتخلص من المؤشر. لا تعديل لعمر query-only navigation المشترك.

لم تتغير أعمدة القوائم وListVMs أو مفاتيح الفلاتر أو معرفات الكتابة أو الترقيم أو حالات الأعمال. تقرير الإجبار يضيف `assignedAt` و`assignedBy` بحسب DTO الخلفية المجمد لتفسير الأحداث المتكررة. نوع السعر TypeScript كان number أصلًا ويلائم decimal في الخلفية التي يملكها المسار الآخر. لا derived quantity أو مبلغ من المرجع صار سلطة مالية. التحقق الخلفي والمخطط والترحيل عند مسار الخلفية والجذر.

## المتبقي وحدود النتيجة

لا تنفيذ للمصفوفة الديناميكية أو موفر تتبع حي أو تغيير سياسة الإحداثيات بهذه الشريحة؛ لا تُعد مغلقة بالمظهر. دلالة forced الجديدة وتاريخ الحدث يملكهما مسار الخلفية بعد تجميد الجذر اللاحق؛ أعمدة التقرير وفلاتره الحالية لا تحتاج API واجهة جديد. شاشة التتبع الثابتة لم تتغير، ولا يُدّعى أنها أصبحت حية. دليل الاستخدام والترجمات يملكهما الجذر؛ أُبلغ بالحاجة إلى `general.screenContextChanged` و`general.financialPolicyUnavailable` و`limousineUtilizationReport.rangeTooLong`، وتعليمات إعادة فتح الجلسة والسعر الكسري وسياسة التحديث.

لا مالك مشترك جديد استحق الاستخراج: السلوك يستخدم المالكين القائمين، وcallbacks الحالية مرتبطة بالنماذج والعمل الخاص بالميزة. لا تغيير للشكل أو palette أو override هندسي محلي؛ المعاينة الفعلية للعرض والثيم وRTL والأحجام تبقى معلقة.

## التحقق

رُوجعت الفروق المحددة لكل الملفات المعدلة في الملكية، ونجح `git diff --check`. تمت قراءة نحوية فقط لـ43 ملف TypeScript غير اختباري في المجلدات الثمانية عبر `createSourceFile.parseDiagnostics`، وقراءة نحوية لـ12 قالبًا عبر `parseTemplate`؛ بلا أخطاء نحوية. هذه ليست type-check أو compilation أو template binding validation أو اختبارًا؛ لا ادعاء نجاح بناء.

لم تُشغّل builds/tests/lint/browser/app/database/migrations/Graphify/commits. لا قياسات زمن أو SQL/IO قبل/بعد في هذه الشريحة؛ عدد واستدعاءات HTTP يعتمد hit الكاش وحجم البيانات. تبقى خطة المالك الموثقة بالمراجعة لفحص البارد/الدافئ وTTL/الإبطال وتغيير السياق أثناء bootstrap والتأكيد والحفظ والطباعة والتصدير، مع فشل المظروف والنقل والإكمال الفارغ، ومقارنة اكتمال الصفوف قبل/بعد. لا migration من تعديل واجهة؛ مسار الخلفية يبلّغ أثر decimal/العداد والفهرس والفرع المستقل.
