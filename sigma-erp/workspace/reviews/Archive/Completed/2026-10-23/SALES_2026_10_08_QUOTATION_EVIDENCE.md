## Frozen contracts consumed

Grid order after automatic Actions: no(text), date(date), validUntil(date), customerName(text), customerCode(text), amount(money), status(status). Backend ListVM has exactly these plus id and salesAgreementId (downstream action). Filters no/customerId/dateFrom/dateTo/status map through Filters[key], with sortField/sortOrder and clamped page size1..100. Empty values omitted; current-month default; Search applies a snapshot retained for actions/export/editor return.

Editor/write inputs: date (required, at most today+30); validUntil optional >=date; customerId required; termsAndConditions<=10000; downPayment>=0 and <=total; numberOfInstallments Int32 1..120; full-snapshot items with saved id on Update, modelId, notes<=500, integer unit1..999999, price0.01..999999999.99, resolved settings/optional-zero rate. Server owns numbers, state, totals and floor-per-installment calculation. Saved tax policy and independently rounded quotation-line VAT remain the explicit frozen deviation from document-per-rate guidance.

Actions: Pending->InternallyApproved (confirm) or InternallyRejected (reason5..500); InternallyApproved->CustomerApproved (confirm, validity not expired), CustomerRejected(reason), Pending(Revise confirm). CustomerApproved->InternallyApproved(Unapprove warning) only with no live agreement/nonvoid receipt, inside shared tenant sales lock. Pending/InternallyRejected Edit/Delete; saving a rejected quotation returns Pending. Open agreement navigates to existing live agreement, otherwise create preloaded from valid CustomerApproved quotation; Converted opens linked agreement. Receipt preparation checks approved/converted, positive down payment, no nonvoid receipt; preparation itself does not collect/post money. Actual collection happens in Receipt Save. CustomerRejected has no revise/edit/delete UI action in the current frozen contract.

Routes: list, create, edit/:id, view/:id, historical details/:id alias; typed guard; query params retained on return. Service providedIn=root and environment.baseUrl, global interceptor for mutations; inline skipped read errors retain Result messages. No authorization API exists.
