# مرجع Odoo المكمل لتأجير السيارات

**الأساس سبيد بالدليل والكود؛ وما ينقص أو لا يتضح فيه نبحث عنه في Odoo.**
هذه هي أولوية المراجع التي حددها المالك في ٢ نوفمبر ٢٠٢٦. تُطبق على المفهوم
والسلوك والحقول والحسابات ودورة المستند، داخل نطاق المهمة الحالية. لا يستبدل
مرجع وظيفي قواعد سيجما أو عقدًا معتمدًا، ولا يتحول غياب الشرح إلى إذن لاختراع
قاعدة مالية أو صلاحية.

جُمعت النصوص الرسمية لإصدار Odoo **19.0** عند commit محدد بتاريخ ٢ نوفمبر
٢٠٢٦: **١١ صفحة Rental و٧ صفحات Fleet و١٠١ صفحة مساندة**، مع **٢٩٧ ملفًا
مساعدًا** وترخيص المصدر. لا تضم الحزمة برنامج Odoo أو إضافات تجارية أو كودًا
خلفيًا له. النصوص الإنجليزية الأصلية محفوظة بصيغة RST مع صورها؛ الشرح العربي
ومصفوفة المقارنة طبقة قراءة وتحليل، وليسا ترجمة رسمية كاملة.

اكتمال الفرعين لا يعني أن Odoo القياسي يثبت كل سلوك متخصص لتأجير السيارات؛
الفجوات مثل الوقود والكيلومترات والمخالفات وسالك ودرب وفحص الأضرار تقارن
بسبيد ومصدر سيجما حسب المصفوفة. تجميع الصفحات لا يعني تنفيذ ميزاتها أو فحصها
تشغيليًا في سيجما.
