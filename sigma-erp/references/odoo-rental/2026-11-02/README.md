الوثائق الأصلية محفوظة دون تعديل تحت `originals/` مع مساراتها النسبية، بحيث
تبقى مراجع الصور والملفات المجموعة قابلة للتتبع. لم تُشغل Odoo أو Sphinx،
ولم تُجمع بيانات حساب أو جلسة أو قاعدة بيانات.

## حدود الاكتمال

- اكتمل جرد فرعي Rental وFleet عند المصدر المثبت؛ الفرعان ١٨ صفحة، لا برنامج
  سيارات مستقلًا ولا ضمان تكامل السجلين.
- جُمعت فروع مساندة كاملة محددة للفواتير/المدفوعات/الضرائب/العروض والصيانة،
  وصفحات منتقاة للعملاء والترقيم والتوقيع والمستندات. هذه ١٠١ صفحة لا تعادل كل
  وثائق Odoo المالية أو كل التوطينات أو مزودي الدفع أو تشريعات التوقيع.
- الروابط المنشورة في الفهرس مشتقة من مسار المصدر، ولم يتحقق HTTP لكل رابط؛
  الموقع قد يتغير أو يحتوي صفحة غير منشورة. النسخة المحلية المثبتة هي دليل اللقطة.
- لا تدعي الحزمة أن كل إحالة داخلية في RST لها صفحة محلية؛ الإحالات لفروع خارج
  نطاق الجمع تبقى مصادر إضافية في Odoo. ملفات الفيديو والروابط الخارجية لم تُنزّل.
- الشرح العربي والمصفوفة راجعا دورة التأجير والأسطول والمساند المرتبطة؛ ليس
  جمع ١١٩ ملفًا ادعاء تدقيق دلالي وتشغيلي لكل سطر فيها.
