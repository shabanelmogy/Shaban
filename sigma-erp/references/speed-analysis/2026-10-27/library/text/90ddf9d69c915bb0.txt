How to create vehicle checklist?
This feature is only available on a web application so you need to use the web app available on https://app.speedautosystems.com/Account/Login so login on this link.
This feature is used to create a list of all those items which are issued with the vehicle as compulsory or optional accessories such as Spare Tire, Jack, Baby Seat and GPS etc.
To create a new checklist item click “+ CREATE NEW CHECKLIST ITEM” on right top corner.
Once a checklist item is created you can edit or delete it by clicking “ACTIONS” button attached to it.
This list would be available to you while checking out the vehicle, just tick the items which are being issued with the vehicle and at the time of check in the selected items will be visible so that their return is ensured.
