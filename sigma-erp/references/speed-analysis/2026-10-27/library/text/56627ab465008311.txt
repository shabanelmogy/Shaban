How to Fix Vehicle Damages?
This feature is only available on a web application so you need to use the web app available on https://app.speedautosystems.com/Account/Login so login on this link.
The feature is to remove the damages, which has been repaired/rectified, from the record in the databa So click “Fix Vehicle Damages” in the left navigation panel. Only the authorized person would have the access to this feature.
Enter the plate number of the vehicle of which the damages have been repaired and need to be removed from the database and press “SEARCH” button.
Select the damage and press the “REPAIR” button given below the damage description and ph
The damage will be removed from the database and will not appear in next check-out.
