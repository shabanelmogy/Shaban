How to manage staff?
This feature is only available on a web application so you need to use the web app available on https://app.speedautosystems.com/Account/Login so login on this link.
Click “Staff” link in the left navigation pan This will show you a table on right having the list of all staff already added.
To add a new staff click “+ CREATE NEW STAFF” button on the right top corner.
Fill in the details and click “SAVE” button.
Details about a staff can be edited or staff can be deleted by selecting the “ACTIONS” button attached to it.
