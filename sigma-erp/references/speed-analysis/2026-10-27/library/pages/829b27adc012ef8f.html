How to Generate Reports / How to Check Movement History of Vehicles?

This feature is only available on a web application so you need to use the web app available on https://app.speedautosystems.com/Account/Login so login on this link.

  1. Click “Movements” link in the left navigation pan This will show you a table on the right containing all movements done over the past in the following manner: –
    1. Select a default date or period from the drop-down list or give a date range for which you want to see the movements.
    2. Give plate number of a specific vehicle for which you want to see the movements else leave it blank if you want to see the movements of all vehicles in your fleet.
    3. Give a specific movement number if known as given in the second column of the table under the heading of “No”.
    4. Give reference number if known as given in the fourth column of the table.
    5. By checking the box “Movements with New Damages” will show only those movements, which caused fresh/new damages to vehicles.
  2. You can export to report in Xcel format by pressing the button given for this purpose on the right upper corner of the table.
  3. You can view the details pertaining to a specific movement by pressing the “ACTIONS” button attached to it.
  4. You can see the Check Card of a specific movement by pressing the “ACTIONS” button attached to it.
